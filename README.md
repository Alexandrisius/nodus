# Nodus

**Nodus** — корпоративный портал проектной строительной компании: задачи и проекты с трекингом времени, мессенджер, входящая/исходящая корреспонденция (письмо → резолюция → поручение), согласования. Заменяет облачный Bitrix24 и СЭД «Е-дело». Self-hosted, без облачных зависимостей, установка одной командой.

- **Статус:** скелет монорепо и инфраструктура качества готовы; доменные модули — в работе (см. issues).
- **Центральный сценарий MVP:** письмо → резолюция → поручение-задача с трекингом времени.

## Быстрый старт

Требования: Node.js 24 (`.node-version`), pnpm 10 (`npm i -g pnpm@10`), Docker.

```bash
# Локальная разработка (приложения на хосте, горячая перезагрузка)
pnpm install
pnpm dev        # web :5173 (прокси /api, /socket.io), api :3001, gateway :3002

# Окружение целиком в Docker (как на демо)
cp .env.example .env   # заполнить пароли
docker compose up      # web :3000, api :3001, gateway :3002 + postgres/redis/minio/gotenberg
```

Проверка живости: `GET http://localhost:3001/api/v1/health`, `GET http://localhost:3002/health`.

## Команды

| Команда                                 | Что делает                                                           |
| --------------------------------------- | -------------------------------------------------------------------- |
| `pnpm dev`                              | dev-режим всех пакетов (turbo)                                       |
| `pnpm build`                            | сборка всех пакетов                                                  |
| `pnpm lint`                             | ESLint: границы модулей (I6), размер файлов (I5)                     |
| `pnpm typecheck`                        | строгий tsc по всем пакетам                                          |
| `pnpm test`                             | unit-тесты (Vitest) + тест-кейсы правил линтера                      |
| `pnpm format`                           | Prettier по репозиторию                                              |
| `docker compose up`                     | dev/демо-окружение в Docker                                          |
| `docker compose --profile tunnel up -d` | + Cloudflare Tunnel к nodus.by (нужен `NODUS_TUNNEL_TOKEN` в `.env`) |

## Структура

`apps/web` (React SPA) · `apps/api` (NestJS + Fastify) · `apps/gateway` (WebSocket, Socket.IO) · `packages/contracts` (zod-схемы, DTO — единственная точка обмена) · `packages/config` (tsconfig/ESLint-пресеты) · `tests/lint` (тест-кейсы правил линтера) · `infra/` (nginx и др.) · `docs/` (документация). Полная схема — `docs/architecture/repository-structure.md`.

## Принципы (кратко)

Модульный монолит в монорепозитории · API-first · связность модулей только событиями и контрактами · оптимистичный UI · self-hosted, zero cloud · русская деловая терминология в интерфейсе. Полный список — `docs/architecture/invariants.md`.

## Участие в разработке

Разработка ведётся ИИ-агентами под управлением владельца продукта; задачи — только через GitHub Issues (см. `docs/process/workflow.md`).
