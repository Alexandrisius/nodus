# @nodus/contracts

Единственная точка обмена между фронтом, бэком и модулями (I3, I6): zod-схемы DTO, типы доменных событий, коды ошибок, константы прав, i18n-строки.

## Правила

- Только схемы, типы и константы — никакой логики и вычислений.
- Запрещено дублировать DTO/типы в `apps/*` — импорт только отсюда.
- Пакет не зависит от других пакетов монорепо.
- Имена файлов — kebab-case, один контракт = один файл; barrel только корневой `src/index.ts`.

## Состав

- `health/` — схема ответа `GET /api/v1/health` (образец паттерна: zod-схема + `z.infer`-тип, используется и бэком, и фронтом).
