# Расширенные описания модулей

Сюда складываются подробные спецификации модулей (потоки, состояния, права, лимиты), когда им становится тесно в `docs/architecture/modules.md` и `README.md` модуля.

Пока модулей нет — код не написан. Первые документы появятся вместе с соответствующими issues.

Правила:
- Один файл на модуль: `<module>.md`.
- Не дублирует README модуля: README — краткая карточка (назначение, контракты, события, лимиты), здесь — глубина (сценарии, диаграммы состояний, решения по правам).
