# ADR-0019: Десктоп-клиент — тонкая оболочка Tauri 2 и мост «веб → оболочка»

## Статус

Принято (2026-10-08, issue #254, M17; решения владельца — инкубатор 08.10, два раунда).

## Контекст

Декабрьский запуск 20.12.2026: у мессенджера должны быть уведомления вне браузера
(веб-вкладка закрывается — уведомления умирают), а обновления клиентов не должны
ложиться на сисадмина руками (боль Битрикса: MSI на каждую машину). Весь
функционал Nodus — веб-интерфейс на сервере портала, поэтому десктоп = тонкая
оболочка: окно с удалённым URL + трей + кастомные попапы уведомлений. Контент
обновляется деплоем сервера; переустановка — только при смене самой оболочки,
тихо и с нашего сервера (не GitHub: репозиторий приватный, I11 zero-cloud).

Решения владельца (инкубатор 08.10): Tauri 2, не Electron; только кастомные
попапы-стеки с быстрым ответом (нативные Windows-тосты исключены из MVP); одна
финальная приёмка; Windows 10/11 только; вкладки — после декабря; адрес портала —
экран первого запуска или зашивка в установщик (модель Битрикса).

## Решение

### Оболочка (Rust, `apps/desktop`)

- Главное окно — **webview с удалённым URL портала**; бандл веб-приложения внутрь
  не встраивается. Пока адрес не задан, окно грузит **локальный мини-фронтенд
  оболочки** (экран «Адрес портала», офлайн/обновительные заглушки), затем
  `WebviewWindow::navigate()` переключает webview на портал. Так один и тот же
  webview несёт и локальные, и удалённые страницы, а авторизация живёт ровно как
  в браузере (same-origin `/api/v1` + `/socket.io`, редиректов и CORS не нужно).
- Закрытие окна прячет webview в трей (событие, соединение и состояние живут);
  полный выход — из меню трея. Трей: «Открыть Nodus», «Смена сервера…», «Выход».
- Попапы уведомлений — отдельные frameless always-on-top skip-taskbar окна с
  локальным мини-фронтендом (React+Vite, токены `@nodus/ui`): аватар, имя,
  превью, «Ответить» (инлайн-поле), «Открыть», автоскрытие ~6 с (urgent — до
  реакции). Позиция — право-низ **work_area** активного монитора, стек вверх,
  физические пиксели конвертируются в логические (DPI 125% — канон компании).
- Deep link `nodus://chat/<id>` (плагины deep-link + single-instance), автостарт
  (autostart), файловое логирование (log). Обновления — tauri-plugin-updater:
  minisign-подпись (приватный ключ в CI-secrets, публичный зашит в оболочку),
  манифест и установщики раздаёт сервер портала из `/desktop/`.

### Мост «веб → оболочка» (главная развилка, research-спайк Ф0)

**Выбран вариант (a′): Tauri IPC + динамическая runtime-capability.**

Механизм (проверено по исходникам tauri, crates/tauri/src/ipc/):

1. Веб-приложение портала получает мост `window.nodusDesktop` через
   **initialization script**, который оболочка инъектирует в webview (исполняется
   в каждой странице, включая удалённые, до её скриптов). Команды моста идут
   через штатный `window.__TAURI_INTERNALS__.invoke` (штатный канал Tauri; CSP
   портала не мешает — портал CSP не выставляет, а если выставит — нужно
   разрешить `connect-src http://ipc.localhost`).
2. Доступ удалённого происхождения к IPC в Tauri 2 разграничен ACL-капабилитями.
   Статические `remote.urls` не годятся — адрес портала вводится в рантайме
   (on-premise = любой адрес). Решение: фича крейта `dynamic-acl` +
   `app.runtime_authority().add_capability(CapabilityBuilder…remote(строка-URL)…)`
   **после валидации адреса пользователем**: capability даёт ровно введённому
   origin'у ровно минимальный набор команд оболочки (`shell-bridge:allow-*` —
   показать попап, бейдж, мигание, фокус, deep-link-эмиттер). При смене адреса
   capability не пересоздаётся по identifier — приложение перезапускается с
   чистым ACL (смена сервера — редкое действие из меню трея).
3. Обратное направление «оболочка → веб» — `webview.eval()`: Rust пушит в
   портал события (`popup-reply`, `deep-link`, `focus-conversation`) вызовом
   `window.__nodusDesktopInvoke(type, payload)`, который зарегистрирован тем же
   initialization script'ом. Токен и креды мост не переносит никогда: логика
   уведомлений (непрочитанные, правила тишины M8, фокус беседы) остаётся в
   веб-приложении, оболочка — только исполнитель команд дисплея.

Отклонённые альтернативы развилки:

- **Статические `remote.urls`** — требуют знать origin на сборке (корпоративная
  поставка с зашитым адресом могла бы генерировать capability build-time, но экран
  первого запуска с произвольным адресом так не работает; wildcard
  `http://*:*` открывает IPC любой странице в webview — отвергнуто по безопасности.
- **init-script + собственный канал** (navigation-interception / custom-scheme
  fetch) — обход ACL кустарным каналом с той же поверхностью рисков, но без
  штатных гарантий; отвергнуто как более хрупкое и менее аудируемое.
- **socket.io-client в мини-UI оболочки** — дублирует логику непрочитанных,
  требует CORS на gateway и хранения токена в оболочке; отвергнуто (запасной
  путь, если IPC-мост не взлетит на парковке WebView2).

### Контракт с сервером

- `GET /api/v1/desktop/config` (публичный, без авторизации — нужен до логина):
  `{ serverName, minShellVersion }`. Оболочка ниже минимума показывает экран
  «обновите приложение»; serverName — идентификация сервера на экране подключения.
- Обновления: `GET <портал>/desktop/latest.json` (статика nginx из
  `NODUS_DESKTOP_DIR`), NSIS-установщик тихо ставится updater'ом
  (`installMode: quiet`). Эндпоинт задаётся в рантайме из сохранённого адреса
  портала (`updater_builder().endpoints(...)`).

## Последствия

- Плюсы: токен не покидает веб-приложение; ACL точно адресован; один движок
  WebView2 на всём парке; «облачные» обновления контента деплоем сервера.
- Риски/меры: (1) remote-origin IPC — обязательный security-reviewer по diff
  (карта в DoD); обязательны свежие версии Tauri (GHSA-7gmj-67g7-phm9 —
  origin-confusion в `is_local_url` на Windows, закрыт в 2026-04; коммит
  7a2672f «enforce ACL for remote origins even without AppManifest»): пин
  минимум 2.10;
  (2) `dynamic-acl` — non-default фича крейта: поверхность стабильна, но
  проверяется живой сборкой; (3) WebView2 на чистых Win10 — докатка
  bootstrapper'ом установщика (`webviewInstallMode: downloadBootstrapper`);
  (4) замеры DPI — по rendered-боксам (урок мини-бейджей), физ/логические
  пиксели конвертируются явно.
- Инварианты: I11 (self-hosted, обновления с нашего сервера) — чисто; I6
  (мини-UI оболочки использует `@nodus/ui` — допустимый общий пакет);
  I2 (API-first — контракт `desktop/config` в `@nodus/contracts` + OpenAPI);
  I12 (README apps/desktop, tech-stack, gotchas — тем же PR).
