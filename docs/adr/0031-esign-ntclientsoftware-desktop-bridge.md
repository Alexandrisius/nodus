# ADR-0031. ЭЦП: подпись через клиентскую программу НЦЭУ NTClientSoftware — только мост десктоп-оболочки

- **Статус:** Предложен (уточняется спайком на реальной флешке руководства)
- **Дата:** 2026-10-25
- **Контекст:** вердикт владельца 23.10 («ЭЦП — сделать, если без закупок»), 24.10 («отдельный блок в конце декабря»), 25.10 («вся работа — в десктоп-приложении, браузером не пользуются»; номер исходящего — не внутри подписанного PDF), ADR-0019, ADR-0027, #427.

## Контекст

Руководство подписывает исходящие ЭЦП «по флешке» (AvPass/AvBign, ID-карта). Бесплатная клиентская программа НЦЭУ NTClientSoftware работает на компьютере подписанта как локальный веб-сервис (`http://127.0.0.1:8084`, например `POST /sign_kta_cms` с `{data: base64, isDetached: true}` → `{sig}` или `{error}`; PIN запрашивает сама программа). Из браузера такой вызов с Chrome 142 требует разрешения Local Network Access и HTTPS, а политика CORS программы неизвестна.

## Решение

1. **Подпись — только через десктоп-оболочку** (Tauri, ADR-0019): команда моста отправляет файл в NTClientSoftware по `127.0.0.1:8084` (без ограничений браузера), возвращает отсоединённую CMS-подпись. В браузере кнопка «Подписать ЭЦП» недоступна с подсказкой «подпись — в приложении Nodus».
2. **Где:** окно отметки «Подписать» в статусе «На подписи» исходящего письма (сбор «любой 1», ADR-0025): варианты «ЭЦП» или «подписано на бумаге — скан приложен».
3. **Хранение:** подпись `.sig` хранится рядом с подписанным файлом (`FileObject`, связь файл ↔ подпись), плюс данные сертификата подписанта (разбор ASN.1: владелец, организация, серийный номер, срок, время подписи). Подписанный файл неизменяем; номер исходящего (присваивается после подписи) — в карточке, теме письма и сопроводительном тексте. Отправка по почте прикладывает файл и `.sig`.
4. **Проверка подписи:** средствами клиентской программы (если API позволяет); серверная проверка алгоритмов СТБ (bign/belt) — позже.
5. **Спайк — первый шаг issue:** получить КП и «Руководство оператора КП», проверить подпись AvPass/AvBign и ID-карты, формат ответа, ошибки, коды; при провале — отметка «подписано ЭЦП» + скан, модуль в январе.

## Альтернативы

| Альтернатива | Почему отклонена | Когда пересмотреть |
|---|---|---|
| Вызов из браузера | Chrome LNA, HTTPS, неизвестный CORS; браузером не работают | Появится веб-клиент для подписантов |
| Веб-плагин Авест AvCMXWebP | Ещё одна установка и тот же браузерный путь | Если КП не подойдёт по API |
| Подпись на сервере | Ключ на флешке руководителя — подписывать можно только на его компьютере | — |

## Последствия

**Проще:** нет закупок; подписанты остаются в Nodus. **Сложнее:** обновление десктоп-оболочки (MSI/автообновление); зависимость от установленной КП и драйверов Авест на трёх компьютерах.
