# ADR-0023. Публичная лицензия Elastic License 2.0

- **Статус:** Принят
- **Дата:** 2026-10-23
- **Контекст:** прямое указание владельца 23.10.2026 — код открыт для всех: пользоваться и менять может кто угодно, зарабатывать на продукте в коммерческих целях нельзя.

## Контекст

Репозиторий публичный (AGENTS.md: «публичный, opensource»). Лицензии не было. Требование владельца переводится в юридическую модель: свободное **использование и модификация всеми** (включая внутреннюю эксплуатацию в коммерческих компаниях — целевая аудитория портала, `vision.md`: «open-source ready, установка одной командой») при **запрете монетизации самого продукта** (продажа, предоставление как платный хостинг/услуга). Такую модель называют fair-code / source available.

## Решение

Публикуем код под **Elastic License 2.0** (текст — в корне `LICENSE`, SPDX `Elastic-2.0`, то же значение в поле `license` корневого `package.json`). Простое изложение для пользователей — раздел «Лицензия» в `README.md`; вклад в репозиторий лицензируется на тех же условиях (`CONTRIBUTING.md`).

ELv2 разрешает использовать, копировать, распространять и модифицировать ПО любому лицу и запрещает ровно три вещи:

1. предоставлять продукт третьим лицам как hosted/managed-услугу (SaaS);
2. обходить лицензионные ключи (для Nodus неприменимо — ключей нет, оговорка стандартна);
3. убирать/затирать уведомления о лицензии и авторстве.

Внутреннее коммерческое использование (компания развернула Nodus у себя для своих процессов) — разрешено без ограничений.

## Альтернативы

| Альтернатива | Почему отклонена | Когда пересмотреть |
|---|---|---|
| MIT / Apache-2.0 | Разрешают любой коммерческий заработок на продукте — прямо против требования владельца | Если владелец сменит политику на полностью открытое ПО |
| AGPL-3.0 | Коммерцию разрешает; коплефт обязывает открывать изменения — против «меняют как всем вздумается»; плюс отпугивает юротделы компаний | Никогда по текущему требованию |
| PolyForm Noncommercial 1.0.0 | Запрещает компаниям внутреннее коммерческое использование (sourceavailable.org: «a commercial company's internal use is the prohibited case») — убивает целевой сценарий «организация ставит портал себе» | Никогда: противоречит vision |
| CC BY-NC 4.0 | Creative Commons сами не рекомендуют свои лицензии для ПО (нет терминов про исходный код и модификации) | Никогда |
| n8n Sustainable Use License | Одновендорная лицензия без SPDX ID, без сообщества Adopters; то же самое даёт ELv2 со стандартным текстом | Нет оснований |
| BSL 1.1 / Fair Core License | Авто-конверсия в полностью открытую лицензию (MIT/Apache) через 2–4 года — монетизация чужими руками становится легальна по прошествии срока | Нет оснований |

## Последствия

- **Становится проще:** любая организация может развернуть и дорабатывать Nodus без юридических трений; владелец сохраняет полное авторство и право выдавать отдельные коммерческие лицензии по договору.
- **Становится сложнее:** репозиторий формально не OSI-open source (определение OSI требует не ограничивать поле применения) — честное имя модели «source available»; часть корпоративных политик закупок и GitHub-фильтры «open source» его не пропускают. GitHub определяет и показывает ELv2 по файлу LICENSE.
- **Остаточный риск:** взимание платы за распространение копий ELv2 не запрещает (перераспределение разрешено) — при свободном скачивании из репозитория это не бизнес; усилить запрет стандартной лицензией нельзя, не запретив заодно внутреннее коммерческое использование.
- **Вклад извне:** без CLA патчи сохраняют авторство вкладчиков — исключительное relicensing всего кода владельцем в будущем потребует CLA. Пока фиксируем в `CONTRIBUTING.md`, что PR = согласие на ELv2 для вклада; CLA — если появится реальная коммерческая потребность.

- Текст и позиционирование ELv2: https://www.elastic.co/licensing/elastic-license
- Каталог source-available лицензий и их ограничений (Elastic 2.0, PolyForm-семейство, n8n SUL, BSL/FCL): https://sourceavailable.org/list-of-source-available-licenses/ ; разбор «почему PolyForm Noncommercial запрещает внутреннее использование компаниями»: https://sourcetrust.dev/licenses/source-available

- Практика выбора ELv2 с той же мотивацией (запрет монетизации сервисом, свобода внутреннего корпоративного использования, battle-tested короткий текст): сравнение ELv2/PolyForm/BSL — публичные решения проектов (пример: docs.asnotes.io/licence.html, таблица «Prohibits competing products / all commercial use / auto-converts to OSS»)
- Русскоязычного стандарта с нужными свойствами не существует; самописная лицензия неприемлема (юридически не выверенный текст).
