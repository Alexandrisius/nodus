# ADR-0018: Превью ссылок — linkpeek + многослойный SSRF-контроль

## Статус

Принято (ночной прогон #212, 05.10.2026).

## Контекст

Сообщения чата несут голые URL; все мессенджеры разворачивают ссылку в карточку
(Open Graph). Превью требует внешнего фетча недоверенного HTML — канонический
вектор SSRF (RFC1918, cloud-metadata 169.254.169.254, DNS-rebinding,
редирект публичный→приватный). Спека #212: BullMQ-конвейер, кэш по
нормализованному URL, TTL 24ч/отрицательный 1ч, lazy-прогрев.

## Решение

**linkpeek** (зависимость `linkpeek`, MIT; `undici` для pinned-DNS агента) + собственные слои (security-ревью добавил pinned-DNS):

- linkpeek из коробки: блок литеральных приватных IP (`PRIVATE_NETWORK_BLOCKED`), ручные редиректы, стрим `maxBytes`, `timeout`, UA. **Известное ограничение:** DNS не резолвит — проверка только по литералу хоста.
- Наши слои (unit-тесты + живой SSRF-прогон):
  - **pinned-DNS undici-агент** (`safe-fetch.ts`): КАЖДОЕ соединение (страница через linkpeek `fetch:`-инжект, og:image, все редирект-хопы) резолвится нашим lookup — ВСЕ A/AAAA против приватных/зарезервированных диапазонов (`ip-ranges.ts`), коннект пиннится на проверенный адрес. Закрыто: hostname-alias «домен → приватный IP», TOCTOU между проверкой и коннектом, редиректы og:image на внутренние адреса/порты.
  - порт только 80/443/не указан; без кредов в URL; self-domain short-circuit (`nodus.by`, env); лимиты длин полей; sharp `limitInputPixels 4096²` (декомпрессионные бомбы); per-user Redis-счётчик ~30/час; отказ = заглушка-карточка из домена (I11).
- Альтернатива `fetch + htmlparser2` отклонена: дублирует зрелую поверхность linkpeek — больше своего SSRF-кода = больше риск.

## Последствия

- Новая зависимость — фиксируется здесь (правило «зависимости без ADR
  запрещены»); карточка и og:image/favicon скачиваются в SILO через
  файловый конвейер #139 (sharp-дериват ≤640px webp) — без хотлинков.
- Конвейер: слушатель `chat.message_sent/edited` (I9) → BullMQ
  `chat-link-preview` (jobId = нормализованный URL — дедуп) → кэш
  `link_previews` → WS `chat.link_preview_ready` (комната беседы).
