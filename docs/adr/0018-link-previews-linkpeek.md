# ADR-0018: Превью ссылок — linkpeek + многослойный SSRF-контроль

## Статус

Принято (ночной прогон #212, 05.10.2026).

## Контекст

Сообщения чата несут голые URL; все мессенджеры разворачивают ссылку в карточку
(Open Graph). Превью требует внешнего фетча недоверенного HTML — канонический
вектор SSRF (RFC1918, cloud-metadata 169.254.169.254, DNS-rebinding,
редирект публичный→приватный). Спека #212: BullMQ-конвейер, кэш по
нормализованному URL, TTL 24ч/отрицательный 1ч, lazy-прогрев.

## Решение

**linkpeek** (зависимость `linkpeek`, MIT; `undici` для pinned-DNS агента) + собственные слои (security-ревью добавил pinned-DNS):

- linkpeek из коробки: блок литеральных приватных IP (`PRIVATE_NETWORK_BLOCKED`), ручные редиректы, стрим `maxBytes`, `timeout`, UA. **Известное ограничение:** DNS не резолвит — проверка только по литералу хоста.
- Наши слои (unit-тесты + живой SSRF-прогон):
  - **pinned-DNS undici-агент** (`safe-fetch.ts`): КАЖДОЕ соединение (страница через linkpeek `fetch:`-инжект, og:image, редирект-хопы) резолвится нашим lookup — ВСЕ A/AAAA против приватных/зарезервированных диапазонов (`ip-ranges.ts`), коннект пиннится на проверенный адрес. Закрыто: hostname-alias «домен → приватный IP» и TOCTOU между проверкой и коннектом.
  - **Литеральные адреса — гвард ДО коннекта** (`assertFetchableUrl` + `isPrivateHost` linkpeek: полный v4/v6/mapped/NAT64-парсер): Node `net.connect` для литеральных хостов не вызывает lookup агента — поэтому og:image качается РУЧНЫМ циклом редиректов (≤3, паттерн linkpeek `manual`+`Location`) с полным гвардом на КАЖДОМ хопе (схема/порт 80/443/креды/литеральный приватный). Публичный порт на хопе редиректа также ре-ассертится.
  - self-domain short-circuit (`nodus.by`, env); лимиты длин полей; sharp `limitInputPixels 4096²` (декомпрессионные бомбы); per-user Redis-счётчик ~30/час; отказ = заглушка-карточка из домена (I11).
- Альтернатива `fetch + htmlparser2` отклонена: дублирует зрелую поверхность linkpeek — больше своего SSRF-кода = больше риск.

## Последствия

- Новая зависимость — фиксируется здесь (правило «зависимости без ADR
  запрещены»); og:image скачивается в SILO через файловый конвейер #139
  (sharp-дериват ≤640px webp) — без хотлинков. **favicon в v1 не
  качается** (колонка favicon_file_id — задел): иконка вторична для
  карточки, домен уже в ней; включение — отдельной правкой при желании.
- Конвейер: слушатель `chat.message_sent/edited` (I9) → BullMQ
  `chat-link-preview` (jobId = нормализованный URL — дедуп) → кэш
  `link_previews` → WS `chat.link_preview_ready` (комната беседы).
