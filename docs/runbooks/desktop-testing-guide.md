# Инструкция тестеру: десктоп-приложение Nodus

Короткая инструкция для тестовой группы: установка, первый вход, что
проверять. Для сисадмина (тихая установка через GPO, раздача обновлений) —
`desktop-deploy.md`.

## Установка

1. Возьмите установщик `Nodus_1.0.0_x64-setup.exe` (или MSI для тихой
   установки) — раздаёт координатор теста.
2. Запустите двойным кликом → «Далее» → «Установить». Ярлык «Nodus» появится
   на рабочем столе и в меню «Пуск». Windows SmartScreen может предупредить
   о неизвестном издателе (файл подписан внутренним сертификатом, не покупным)
   — нажмите «Подробнее» → «Выполнить в любом случае».
3. Требование: Windows 10/11 и установленный WebView2 (есть на всех актуальных
   Windows; если его нет — установщик предложит скачать).

## Первый запуск

1. Откроется экран «Подключение к порталу»: введите адрес, который дал
   координатор (например, `https://nodus.by`), → «Подключиться».
2. Введите обычный логин/пароль портала (те же, что в браузере).
3. Приложение живёт в трее: закрытие окна (крестик окна) не выход — сворачивает
   в трей. Выход совсем — правый клик по иконке в трее → «Выход».

## Что проверять

- **Уведомления**: попросите коллегу написать вам сообщение. Пока окно
  свёрнуто или перекрыто — справа-внизу появляется попап. Они копятся (до 3 на
  экране, остальные в очереди), НЕ исчезают, пока вы не отреагируете; если вы
  работаете за ПК (кликаете/печатаете где угодно) — медленно гаснут за ~3 c.
  Наведите курсор на попап — он снова станет ярким.
- **Быстрый ответ**: в попапе «Ответить» → строка ввода → Enter — сообщение
  уходит в чат без открытия окна.
- **Клик по попапу** — открывает беседу.
- **«Скрыть все»** (появляется, только когда ровно 3 попапа) — гасит всё.
- **Бейдж** непрочитанных — на иконке приложения в панели задач; после прочтения
  гаснет.
- **Сворачивание в трей**: закрыли приложение крестиком окна → оно в трее и
  уведомления продолжают приходить.
- **Тема**: попапы следуют теме приложения (переключатель в настройках
  портала), не теме Windows.
- **Deep-link**: ссылка вида `nodus://chat/…` из портала открывает беседу в
  приложении.

## Известные ограничения (не баги)

- Крестик попапа не разворачивает свёрнутое приложение — это сознательно
  («закрыл = занят»).
- Вложения и упоминания из быстрого ответа попапа не отправить — только текст.
- Уведомления задач/корреспонденции в попапах — следующая итерация.

## Куда сообщать о проблемах

Соберите лог (правый клик по иконке в трее → «Открыть логи» или
`%APPDATA%\by.nodus.desktop\logs\`) и опишите шаги воспроизведения — отправьте
координатору теста.
