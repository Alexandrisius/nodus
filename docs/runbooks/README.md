# Runbook-и (эксплуатационные процедуры)

Пошаговые процедуры эксплуатации портала. Каждый runbook — проверяемая последовательность команд, а не эссе.

Появятся вместе с инфраструктурным скелетом (issue «Скелет монорепо») и дополняются к пилоту:

- **уже есть: `repo-bootstrap.md`** — создание GitHub-репозитория и базовый коммит (одноразовая процедура, выполняется по команде владельца);

- установка и первичная настройка;
- обновление и откат;
- бэкап и восстановление (PostgreSQL + MinIO, проверка восстановления);
- TLS: выпуск/обновление сертификатов (dev: Cloudflare Tunnel — см. ADR-0002; прод: Caddy);
- ротация токенов;
- добавление сотрудника;
- сидинг локальной dev-БД и её сброс до seed (политика данных по средам — ADR-0002);
- доступ к БД (с двумя подписантами — см. `docs/architecture/non-functional-requirements.md`, безопасность);
- настройка Cloudflare Tunnel для `nodus.by` (dev/демо).

Формат: цель → предусловия → шаги (команды) → проверка результата → откат.
