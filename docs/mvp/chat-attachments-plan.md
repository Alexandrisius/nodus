# План: вложения сообщений — грамматика отображения и задел на будущее

**Статус:** план составлен 14.09.2026 по вердикту владельца; РЕАЛИЗАЦИЯ — после его «ок».
**Рефы владельца:** скриншоты Битрикс24 — пост канала с файлом и с галереей изображений,
личное сообщение с файлом и с крупной галереей.

## Проблема сейчас

Вложения — плоские чипы `Attachment` внутри пузыря; изображения не отличаются от файлов
(нет галереи); схема контракта бедная (`id/name/size/mime`) — под будущие загрузку,
галерею и лайтбокс её придётся переписывать с нуля. Цель владельца: разобрать
отображение СЕЙЧАС так, чтобы будущая полноценная работа с вложениями легла без переделки.

## Контракт: расширяем схему `messageAttachment` СРАЗУ

- `kind: 'image' | 'file'` — явно (не выводить из mime: mime нужен для иконки и валидации);
- `url: string | null` — адрес оригинала (в проде — MinIO через `StorageDriver`, I13;
  в моках — локальные статичные ассеты);
- `thumbnailUrl: string | null` — превью для галереи (у файлов `null`);
- `width: number | null`, `height: number | null` — габариты изображения: раскладка
  галереи стабильна до загрузки (aspect-ratio, без дёрганий ленты);
- `name`, `size`, `mime` — как сейчас.

**Задел на загрузку (НЕ реализуем в этом заходе):** `POST /api/v1/chat/attachments`
(multipart) → attachment ref; сообщение хранит refs. Точка расширения уже есть —
интерфейс `StorageDriver` (I13). Схема выше переживёт это без изменений.

## Грамматика отображения (по рефам Битрикс)

Порядок внутри пузыря СВЕРХУ ВНИЗ: **галерея изображений → чипы файлов → текст →
нижняя строка (реакции слева + время/галочки справа)**.

- **Галерея:** 1 изображение — крупное превью на всю ширину пузыря (max-h ~340px,
  radius 10, object-cover); 2+ — сетка 2–3 в ряд равной высоты (~140px). Галерея задаёт
  ширину пузыря (пузырь с галереей шире чисто текстового). Клик по превью — лайтбокс
  (следующий шаг; сейчас клик неактивен, точка подключения уже в компоненте).
- **Файлы:** чип-строка: иконка по mime (PDF/документ/архив/иное), имя (truncate),
  размер, кнопка скачивания справа (сейчас — `href=url`).
- **Смешанные:** сначала галерея, затем чипы файлов.

## Компоненты (`shared/chat`)

- `attachments.tsx` — входная точка (нынешний `MessageAttachments`): делит вложения на
  изображения/файлы, задаёт порядок блоков;
- `attachment-gallery.tsx` — крупное превью / сетка; проп `onOpen(index)` — точка
  подключения лайтбокса (сейчас noop);
- `attachment-file.tsx` — чип файла.

**Лайтбокс (будущее):** `shared/ui/lightbox.tsx` — портал, стрелки/Esc, счётчик «3 из 7»;
интерфейс `onOpen` в галерее закладывается сейчас, чтобы подключение не трогало ленту.

## Моки

Схема += поля; демо-набор показывает все ветки грамматики: пост канала с галереей из
2 изображений, личное сообщение «файл + изображение», тред с файлом. Изображения —
локальные ассеты `apps/web/public/demo/*.jpg` (self-hosted, zero cloud, I11).

без регресса.
