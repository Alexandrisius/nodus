## Лог запросов (семейства формулировок по раундам)

- Раунд A (09–10.10, до навыка): синонимия боли + инструменты (MSP/Asana/Jira/Pipefy/Tallyfy) + стандарты (ISO 19650, СП 246, ГОСТ 21.10x, П-1476) + RU-язык + смежные (PMO/портфель, My Day). Закрыты семейства 1, 2, 3, 5(RU), 4(частично: PMO).
- Не закрыты: EN-формулировки (5), сленг/просторечие (6), смежные индустрии глубже (4). → кандидаты в раунд жатвы 2 (после атак, при наличии FAIL по этим зонам).
- Benchmark-эталоны (проверка формулировок): «потеряли версию чертежа» ✔ (C1/C3), «смета по старому проекту» ✔ (C2), «стройка по устаревшему чертежу» ✔ (C4/C1), «кто получил какую редакцию» ✔ (C3), «задание смежнику потерялось» ✔ (C4). Все найдены — формулировки не узкие.
