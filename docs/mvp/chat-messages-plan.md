# План: ленты чатов как в Битрикс24/Телеграм — стаки сообщений, хвостики, анатомия пузыря

**Статус:** план составлен 14.09.2026 по вердикту владельца; РЕАЛИЗАЦИЯ — только после его «ок».
**База:** ветка `feat/4-node-ui`, HEAD = коммит фиксации чат-карточки и тонов мессенджера.
**Референсы владельца:** скриншоты Битрикс24 (личные и групповой чаты); research: Telegram-канон
(имя — только первое сообщение серии, аватар — один на серию СНИЗУ, у последнего сообщения —
github.com/GeiserX/Telegram-Archive#229: «round avatar at the bottom-left of each sender's
message run»), хвостики — Smashing Magazine «Modern CSS Tooltips And Speech Bubbles» (техники
tail: clip-path/border-image против SVG; для пузырей с бордюром аккуратнее SVG).

## Требования владельца (формулировки → суть)

- **R1.** В личных чатах (1 на 1) автор НЕ подписывается: участников двое, и так понятно
  (сейчас уже так: `showAuthor=false` для direct — сохранить).
- **R2.** У пузыря сообщения есть **хвостик**, выходящий из низа аватарки пользователя
  (сторона хвостика = сторона аватарки; зависит от настройки выравнивания).
- **R3.** В групповых чатах подписываются (имя автора) **ТОЛЬКО чужие** сообщения и **ТОЛЬКО
  первое** в серии; свои — без имени.
- **R4.** Последующие сообщения серии **стакаются компактно** (плотный вертикальный ритм),
  аватарка у серии **ОДНА** — по скриншоту Битрикс и канону Телеграма: у ПОСЛЕДНЕГО сообщения
  серии (снизу), там же хвостик; первое сообщение серии несёт имя.
- **R5.** Та же логика стаков — в чатах 1 на 1 (серии своих/чужих сообщений).

## Правила группировки (чистая функция, unit-тесты)

`shared/chat/message-groups.ts`: `buildMessageGroups(messages, meId) → MessageGroup[]`,
`MessageGroup = { authorId, mine, items }`. Серия рвётся ТОЛЬКО по:

1. смене автора;
2. смене календарного дня (UTC-дата `createdAt`) — между днями ставится дата-чип (ниже);
   временного порога ВНУТРИ дня НЕТ (модель Телеграма/Битрикс: подряд идущие сообщения одного
   автора — одна серия независимо от паузы; альтернатива «порог N минут» отклонена как
  небитриксовая и требующая настройки).

Не рвут серию: реакции, вложения, правки, оптимистичные (pending) свои сообщения, цитаты.
Каналы (лента новостей-постов `thread-feed`) — БЕЗ группировки: посты остаются полными
карточками с автором и временем в хедере (грамматика новостей, вердикты ранее). Треды
(ответы в окне треда) и обсуждения задач — группировка применяется (это разговорные ленты).

## Анатомия сообщения (новый вид)

- **Имя автора** (групповые/трееды, чужие, первое в серии): строка НАД пузырём — 13px
  semibold `text-foreground`; у серии ниже имени — пузыри без имён.
- **Время**: ВНУТРЬ пузыря, правый нижний угол — моно 10px `muted-foreground` (на своём
  primary-пузыре — `primary-foreground/70`); из хедера над пузырём время УХОДИТ (сейчас
  дублирует роль имени в MessageHeader).
- **Аватар**: один на серию, у ПОСЛЕДНЕГО сообщения серии, на стороне автора: 'one' — все
  слева (свои тоже, настройка выравнивания уже есть); 'both' — свои справа. В личных чатах
  аватары остаются у обоих участников (серии из одного сообщения = как сейчас).
- **Хвостик**: только у ПОСЛЕДНЕГО сообщения серии (где аватар): выходит из нижнего угла
  пузыря в сторону низа аватарки. Реализация — отдельный SVG-компонент
  `shared/chat/bubble-tail.tsx` (12×14px, path с вогнутой кривой): fill = фон пузыря
  (`--card` для чужого outline-пузыря, `--primary` для своего), stroke = `--border` ТОЛЬКО у
  outline-варианта; хвостик рендерится ПОД пузырём (z-порядок: хвост за пузырём, его верхний
  край укрыт телом пузыря — стык бордюров чистый). Сторона: left/right по автору и
  настройке выравнивания. У пузырей без хвостика (середина/верх серии) — обычные скругления.
- **Ритм**: внутри серии — зазор 2px (gap-0.5); между сериями — 12px (gap-3); серия сдвинута
  на ширину колонки аватара всегда (пузыри серии и одиночных сообщений на одной вертикали).
- **Дата-чип**: при смене дня — центрированный чип (моно 10px uppercase, `bg-muted/40`,
  rounded-full, px-2 py-0.5): «Сегодня» / «Вчера» / «5 сентября» (Intl `ru-RU`; строки
  i18n `ui.chat.today`, `ui.chat.yesterday`).
- **Доступность**: у каждого сообщения `aria-label="<автор>, <время>"` (визуальное имя есть
  только у первого в серии — скринридер не должен терять автора).

## Точки правки

1. `shared/chat/message-groups.ts` (+ `message-groups.test.ts`: чередование, серия из N,
   разрыв днём, свои серии, пусто/одно, pending-сообщение в серии).
2. `shared/chat/bubble-tail.tsx` — SVG-хвостик (side, variant).
3. `shared/chat/chat-message.tsx` — пропсы `showName / showAvatar / tail / stacked`; новая
   анатомия (имя над пузырём, время внутри, aria-label); Bubble-примитив не трогаем.
4. `shared/chat/conversation-pane.tsx` и `thread-pane.tsx` — рендер через
   `buildMessageGroups`: флаги isFirst/isLast серии, дата-чипы, зазоры.
5. `shared/chat/thread-feed.tsx` (посты канала) — БЕЗ изменений.
6. i18n: `ui.chat.today`, `ui.chat.yesterday`.
7. Настройки/выравнивание — БЕЗ изменений (хвостик и аватар следуют за стороной автора).

## Приёмка (пробы + живой просмотр обеих тем)

- Личный чат: имён нет; серия из двух своих сообщений (отправить подряд) — один аватар снизу,
  один хвостик у нижнего пузыря, время внутри каждого пузыря; чужое одиночное — аватар+хвост.
- Групповой/тред: чужая серия — имя только над верхним пузырём, аватар только у нижнего,
  хвост только у нижнего; своя серия — без имён, аватар+хвост снизу (one) / справа (both).
- Смена дня в демо-данных (если есть) или рукотворно в моке — дата-чип между сериями.
- Канал: посты без изменений (полный хедер, без хвостов).
- Сквозной скролл/MessageScroller, контекстное меню сообщения и реакции на стаках — без регресса.
