## Главный принцип

**Визуальный слой — с нуля. Слой данных — наследуем.**

- `packages/ui/src/styles/globals.css` — **новый файл** (никаких `texture-paper`, `paper-card`, `paper-surface`, `crayon-fill`, `sketch-tilt` и советской палитры rust/ochre/cream/sage; легаси-темы «Тушь»/«Бумага» при этом НЕ удаляем из кодовой базы — они уходят из дефолта, селектор темы пока оставить скрытым/для dev).
- Каждый экран и хром — **новые компоненты**, не правки старых. В новом коде grep-запрет легаси-утилит (см. DoD).
- Наследуем как есть: `packages/contracts` (i18n — только добавляем строки), `shared/api-client.ts`, MSW-моки и данные (`shared/mocks/`), query-хуки фич (`features/*/api/`), роутер-скелет и механику слайдер-стека/ESC.

## Грамматика стиля

- **Палитра:** фон `#0A0A0B`; панели `#121214`; бордюры `white/8–12%`; текст `#E8E8E6`; вторичный `#8A8A8E`; действие — белый primary (текст кнопки `#0A0A0B`); семантика приглушённая (success/warning/danger/info — холодные, ненасыщенные). Плоско: без текстур, теней, градиентов.
- **Типографика:** Onest — контент; JetBrains Mono Variable (уже в зависимостях) — метки UPPERCASE 11–12px / tracking 0.14–0.16em, ключи сущностей (ПП-142), даты, счётчики.
- **Ребро:** ортогональное (манхэттенская геометрия), 1px, скругление узла 6–8px, порты r=3. Примитив `packages/ui/components/node-edge.tsx` — взять за базу, но **центровку портов вычислять из реальной геометрии линии** (или CSS-трансформами, гарантирующими центр), не константами «на глаз».
- **Панель:** hairline-бордюр, радиус 10px, плоская (`node-panel`).
- **Сетка:** 8px-ритм. Адаптивность экранов на концепте не делаем, но раскладка флюидная, чтобы не заблокировать её позже.

## Фирменные моменты — крупно и честно

1. **Навигация-вспышка:** клик по модулю → пульс-вспышка от логотипа по вертикальной магистрали к порту модуля; модуль загорается; короткое ребро «втыкается» в контент (как TOOLS-связь на рефе). ≤ 400 мс, `prefers-reduced-motion` → мгновенная смена без анимации.
2. **Слайдер-нода:** панель стыкуется ребром **от родительской сущности** (строка задачи/письма) к раме панели: 60–120px, ортогонально, draw-on при открытии + один пробег пульса. Никаких сантиметровых огрызков.
3. **Доменная цепочка** в шапке сущности: Письмо → Резолюция → Поручение → Задача — компактные узлы со связями, кликабельные (реф `03-domain-chain.png`).

## Порядок работ (вертикальный срез, не горизонтальные слои)

1. Примитивы: `node-edge` (доработка), `node-label`, `node-chip`, `node-card`, утилита `node-panel`.
2. Хром с нуля: NodeRail (лого + модули на магистрали), TopBar (моно-вкладки с точкой-портом, поиск Ctrl+K, уведомления, аватар), RightRail (56px), SliderStack с док-рёбрами.
3. **Срез: шелл + Главная целиком** → скриншоты `tests/e2e/shots.mjs` → **UI-чекпоинт владельцу** (стоп до вердикта).
4. Экраны по образцу среза, после каждого — снимок в отчёт: Задачи (список + канбан «Мой план» + карточка-слайдер с обсуждением) → Письма (журнал + карточка с «В поручение») → Проекты → Мессенджер → Сотрудники.
