# UX-принципы и дизайн-каркас

Читать: перед любой работой над UI. Правила терминологии и каркаса — обязательные, не рекомендательные.

## Главный принцип: «знакомая география, новый фасад»

Целевая аудитория — инженеры строительной отрасли, годами работающие в Битрикс24. Главный риск внедрения — отторжение при переучивании, поэтому:

- **Каркас и информационная архитектура повторяют Bitrix24** (переобучение ≈ 0): левое вертикальное меню модулей, подразделы модуля в топбаре, карточная модель сущностей, канбан, колокольчик уведомлений, вертикальная полоса аватарок сотрудников справа, слайдеры.
- **Визуальная кожа — современная** (воздух, крупная типографика, спокойные цвета): пользователь находит любую базовую функцию за ≤ 10 секунд без инструкции, но сразу ощущает «чище, крупнее, быстрее».
- Копируются UX-паттерны и расположение. **Не** копируются код, стили, иконки и графические ассеты Битрикса (лицензия).

## Зафиксированный каркас (не изменяется в экспериментах)

- **Сетка приложения:** левое меню 240px (группы модулей, сворачиваемое) · топбар (подразделы модуля, глобальный поиск Ctrl+K, уведомления, аватар пользователя) · правая полоса аватарок онлайн 56px (сворачиваемая) · рабочая область.
- **Слайдеры:** детальные страницы открываются панелью 60–75% ширины справа поверх текущего экрана; стек панелей с хлебными крошками («Проект → Задача → Файл»), ESC закрывает верхнюю, у каждого уровня стека свой URL (ссылку на задачу/письмо можно отправить коллеге).
- **Карточка задачи двухпанельная:** слева параметры и описание, справа обсуждение (тред чата задачи).
- **Терминология — только русская деловая:** Задачи, Поручения, Письма, Проекты, Согласования, Сотрудники. Айтишные англицизмы в интерфейсе запрещены («ишью», «асайн», «борд» и т.п.). Таблица терминов ведётся в `packages/contracts/i18n/ru.ts`.
- Светлая тема по умолчанию (тёмная — опция); базовый шрифт ≥ 14px; зоны клика ≥ 36px; контраст не ниже WCAG AA; адаптив от 1280px, без горизонтального скролла.

## Тема как данные

Всё визуальное — акцентные цвета, радиусы, тени, плотность сетки, фоновые обои, шрифт (кандидаты: Onest, Inter — оба с полной кириллицей), форма карточек, стиль иконок — задаётся **только дизайн-токенами** (CSS-переменные / тема Tailwind) в `packages/ui`. Смена варианта оформления = подмена набора токенов, без изменения компонентов (I13 применительно к дизайну). Жёстко зашивать значения токенов внутрь компонентов запрещено — контролируется линт-правилом и ревью.

**Процедура выбора стиля (этап концепта):** ИИ-агент готовит 3–5 визуальных вариантов одного набора экранов (канбан «Мой план», карточка задачи с чатом, журнал писем + карточка письма, главная) — все на каркасе выше, отличаются только токенами. Обязательные варианты: «Максимально близко к Битриксу» (эталон привычности), «Тёплый светлый корпоративный» (базовая рекомендация), «Воздушный минимализм». Руководство выбирает один; выбранный фиксируется как единственная тема, остальные наборы токенов удаляются. Страховка: «тест 10 секунд» на пилотной группе — пользователь Битрикса без подсказок находит список своих задач, чат, карточку письма, кнопку создания задачи.

## Персонализация пользователя (фича продукта)

Выбор темы (светлая/тёмная/системная), акцентного цвета, плотности интерфейса (компактная/обычная/просторная) и фоновых обоев — с автоматическим размытием/затемнением под карточками (обои никогда не снижают читаемость). Настройки хранятся на сервере, едины для всех клиентов пользователя.

## UX-референсы и антиреференсы

- **Берём невидимое:** Linear — скорость, клавиатурность, Ctrl+K (не визуальный стиль и не терминологию).
- **Берём видимое:** Telegram — механика чата и попапов уведомлений; VK People Hub и классические корпоративные интранеты — «взрослый» деловой тон для не-IT аудитории; OpenProject — предметные паттерны строительных проектов.
- **Антиреференсы:** Linear/ClickUp как видимый стиль (чуждая айти-эстетика и словарь); плотная мелкая вёрстка Битрикса 2010-х; фото-фоны под контентом без затемняющего слоя.

## Что улучшаем относительно Битрикса (наши «вау»)

1. Скорость: оптимистичный UI (I4), ноль спиннеров на операциях < 300 мс, мгновенный просмотр документов.
2. Уведомления собственные, а не системные Windows (в десктоп-клиенте: кастомные стекающиеся попапы, быстрый ответ из попапа, бейдж в трее).
3. Письмо → поручение → задача в 2 клика без переноса между системами.
4. Глобальный хоткей-поиск (Ctrl+K) по всему: задачи, письма, люди, чаты, действия («создать задачу»).
