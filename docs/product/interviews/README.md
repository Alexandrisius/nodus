# Саммари интервью и обсуждений

Отфильтрованные агентом выжимки разговоров с руководством и сотрудниками (аудио, встречи, переписки), значимые для продукта. Саммари — **главная точка входа**: читается без оригинала и написана в терминах канона — глоссарий, core-flows, roadmap-кейсы, issues. **Полные очишенные транскрипты тех же разговоров — в `full/`** (единый формат, имя файла = имя саммари) — для обращения к оригиналу, когда саммари недостаточно. Вне репозитория остаются только аудио-оригиналы, сырые (дословные, неочищенные) проходы ASR и скриншоты переписок.

## Формат `full/` (полные транскрипты)

- Один разговор = один файл, имя совпадает с именем саммари: `ГГГГ-ММ-ДД-<кто-или-тема>.md`.
- Шапка: дата, длительность, участники, ссылка на саммари, источник и метод расшифровки. Вопросы владельца — реплики с тире «—», ответы собеседника — без пометки; имена говорящих в теле не проставляются.
- Тело: очищенный полный текст (слова-паразиты, повторы и обрывы убраны, **содержание сохранено полностью** — это не саммари). Реплики интервью от 22.10+ — с таймкодами `[ЧЧ:ММ:СС]`; более ранние расшифрованы до введения таймкодов — без них, порядок реплик сохранён.
- Пометки: `[нрзб]`/`[неразборчиво]` — не восстановлено по аудио; `[?]` — неоднозначное место; `*` — исправленное искажение имени/термина ASR (таблица правок — в приложении файла, где есть).
- Правка текста в `full/` = правка соответствующего саммари в том же коммите (один и тот же первоисточник).

## Зачем

Мысли руководства — источник требований, который легко теряется. Здесь они зафиксированы самодостаточно: файл читается без оригинала и написан в терминах канона — глоссарий, core-flows, roadmap-кейсы, issues.

## Правила

- Один разговор = один файл: `ГГГГ-ММ-ДД-<кто-или-тема>.md` (ASCII, kebab-case).
- Шапка: дата, участники, источник и способ расшифровки, что из оригинала отброшено как нерелевантное.
- Тело по темам: суть → «значит для Nodus» (терминами канона, со ссылками). В конце — «Подтверждения канона» (что совпало с уже зафиксированным, чтобы не переизобретать), «Открытые вопросы» и таблица «тема → куда в плане».
- Цитаты — короткие, «близко к расшифровке»; имена из аудио — с пометкой, что могут быть искажены.
- Судьба тем: когда тема превращается в roadmap-кейс или issue, у неё в таблице появляется ссылка `→ #N`. Файлы не удаляются.
- Новые темы не вносятся в roadmap до решения владельца — они ждут в таблице со статусом «не внесено» и живые из них уходят записями в инкубатор (`../incubator.md`) для обсуждения.

## Когда читать

Перед сессиями планирования, нарезкой issues и работой по модулям корреспонденции, проектов, мессенджера и ИИ-контура (V3). Методология проведения интервью — `../process-discovery.md`.

Полные транскрипты (`full/`) по умолчанию в контекст не грузятся — открывать точечно, когда саммари не хватает (нужна цитата, порядок реплик, таймкод, формулировка словами спикера).
