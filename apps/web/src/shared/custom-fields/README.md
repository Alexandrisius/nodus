# shared/custom-fields — кирпичи кастомных полей (#431, ADR-0029)

Общий слой значений и редакторов атрибутов (термин UI — «Атрибуты»):
им пользуются карточка задачи (блок «Атрибуты»), окно перехода и (далее) #432/#435/#469/#55/#52. Грамматика
значений — в `@nodus/contracts` (`custom-field-values.ts`), здесь только
представление, ввод и запросы.

## Правила

- Значения — по id определения, ключ `cf.<uuid>` в окнах и гейтах; `null`
  в правке удаляет ключ (пустое не хранится).
- Тип меняется только расширяюще (text→long_text, enum→multienum,
  user→users); чтение толерантное (`readCustomFieldValue`).
- Правка в карточке оптимистичная: `useUpdateTaskCustomField` кладёт значение
  и ссылку выбора в кэш детали и журналов до ответа сервера, откат — по
  снапшотам (канон patterns.md).
- Скрытый (служебный) атрибут не показывается никому — ни в карточке, ни
  в фильтрах, ни в окне перехода (`visibleDefinitions`); его видят реестр
  и условия процессов.
- Ввод правки по месту — того же габарита, что строка-значение
  (`editorInputClass`/`editorTextareaClass`): активация не сдвигает карточку.
- Ссылки для показа приходят в детали сущности (`customFieldRefs`); строка
  списка несёт только значения.

## Привязка к типам процессов (#432)

Атрибут живёт у типов: `typeIds` в определении, поле «Типы» в окне атрибута
(`features/automation/.../field-types-picker.tsx`), колонка «Типы» в реестре.
Поле — строка-сводка фиксированной высоты (#501): названия выбранных типов
заполняют её по реальному замеру ширины, остаток — плашка «+N»; пустой выбор
сказан в самой строке (под полем текста нет — окно не дёргается). Выбор — в
поповере во всю ширину поля: ведущая отметка, «Выбрать все» с частичным
состоянием и счётчиком, поиск от 7 типов, выбранные сверху (порядок
фиксируется при открытии).
Тип видит только свои атрибуты — карточка (`CustomFieldsBlock` c `typeId`),
форма создания, окна переходов и условия; атрибут без типов не показывается
нигде. Запись значения непривязанного атрибута — 422 `not_in_type`, очистка
разрешена. Привязка/снятие — точечные `PUT/DELETE …/types/:typeId`
(оптимистично, `useBindFieldType`/`useUnbindFieldType`); снятие при
использовании в опубликованном маршруте типа — 409 `CUSTOM_FIELD_IN_USE`.
