# shared/custom-fields — кирпичи кастомных полей (#431, ADR-0029)

Общий слой значений и редакторов: им пользуются карточка задачи (блок
«Поля»), окно перехода и (далее) #432/#435/#469/#55/#52. Грамматика
значений — в `@nodus/contracts` (`custom-field-values.ts`), здесь только
представление, ввод и запросы.

## Состав

| Файл                              | Что                                                                                                                                                                                        |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `queries.ts`                      | `customFieldsKeys`, `useCustomFieldDefinitions(scope?, {archived})`, `customFieldValuesOf(e)` (терпит старый API :5173), `activeDefinitions`                                               |
| `use-can-manage-fields.ts`        | право `custom_field.manage` (в shared: потребители — вкладка «Поля» и карточка, I6)                                                                                                        |

## Правила

- Значения — по id определения, ключ `cf.<uuid>` в окнах и гейтах; `null`
  в правке удаляет ключ (пустое не хранится).
- Тип меняется только расширяюще (text→long_text, enum→multienum,
  user→users); чтение толерантное (`readCustomFieldValue`).
- Правка в карточке оптимистичная: `useUpdateTaskCustomField` кладёт значение
  и ссылку выбора в кэш детали и журналов до ответа сервера, откат — по
  снапшотам (канон patterns.md).
- Ссылки для показа приходят в детали сущности (`customFieldRefs`); строка
  списка несёт только значения.
