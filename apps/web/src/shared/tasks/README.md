# shared/tasks — общие блоки задач

Компоненты и модель, нужные и фиче задач, и её потребителям за пределами
фичи (карточка сотрудника, мессенджер, доска проекта): направление слоёв
`features → shared` (I6, eslint-boundaries).

## Единое окно создания (#432, В1/Р9)

- `task-create-store.ts` — zustand-стор: `open(prefill)` / `close()`;
  `openTaskCreate(prefill)` из любого места.
- `task-create-host.tsx` — ЕДИНСТВЕННЫЙ хост, смонтирован в `app-shell.tsx`
  рядом с `ChatDialogHosts`. Вторых форм в приложении нет.
- `task-create-window.tsx` — окно: верх зафиксирован (название, тип с ⚙ для
  `workflow.manage`), низ — эффективная форма типа (`creationForm`),
  перестраивается на лету; смена типа хранит значения по ключу слота.
  «Создать» неактивна до названия и обязательных полей, строка «Не хватает:
  …» связана через `aria-describedby`; создание пессимистичное (номер,
  стадию и скрытые значения назначает сервер), успех — тост, карточка не
  открывается.
- `task-create-draft.ts` — чистая модель: `emptyDraft`, `withType`,
  `withValue`, `draftBody`, `missingFor`, `buildCreateBody`. Значения живут
  по ключу слота (`description`, `assignee`, `cf.<id>`), поэтому смена типа
  не стирает совместимое; «не хватает» считается грамматикой contracts.
- `task-create-form-body.tsx` / `task-create-fields.tsx` — поля формы:
  подпись слота (своё название → роль типа → стандартное), системные поля и
  атрибуты типа через общий редактор значений (#431); поле с ошибкой 422
  подсвечено.
- `task-create-chips.tsx` — чипы «Чек-лист» (лист поверх формы) и
  «Планируемое время»; включаются настройкой типа.
- `task-create-skeleton.tsx` — скелет низа, пока грузятся типы.
- `quick-create.ts` — быстрые входы (`useQuickCreate`): плюсик колонки,
  плюсик доски проекта, строка подзадачи, «В задачу». Решение «создать сразу
  или открыть окно» — по наличию обязательных полей у типа `task`; типы не
  загружены — создаём, на 422 `PROCESS_TYPE_FIELDS_REQUIRED` открываем окно с
  заполнением.

## Остальное

- `task-checklist-sheet.tsx` — лист чек-листа поверх формы (Esc закрывает
  лист, а не окно).
- `process-type-field.tsx` — выбор типа процесса в формах.
- `comments-count.tsx`, `comments-live.ts` — счётчик и живые обновления
  обсуждения; `task-result-view.tsx`, `time-entry-fields.tsx` — итог и время.
