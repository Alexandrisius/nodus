# features/projects

Проекты в теме «Инструмент»: журнал — каноническая таблица (shared/views
`DataTable`, ключ вида `projects.list`, реестр `shared/views/project-table-fields.tsx`),
карточка проекта — в общем стеке карточек (ADR-0009).

Карточка проекта (`components/project-card.tsx`, вердикт владельца 2026-09-11,
раунд 3) — анатомия карточки задачи: мини-графа цепочки НЕТ, горизонтальных
зон «поля над задачами» НЕТ — **левая зона = вкладки на всю высоту**:

- **Задачи** (главная вкладка, `components/project-tasks-tab.tsx`): СТРОКА
  ИНСТРУМЕНТОВ в зоне задач, не в таб-баре (вердикт раунда 4) — переключатель
  **Список/Канбан** иконками, поисковая строка с панелью фильтра (модель
  Битрикс24: пресеты слева, поля справа; поле «Проект» скрыто), шестерёнка
  активного вида (`projects.tasks` / `projects.kanban`).
- **Гант** (`components/project-gantt.tsx`), **Отчёт** (`project-report.tsx`),
  **Схема** (`project-flow.tsx`) — ВИТРИНЫ будущих модулей (вердикт: показать,
  как будет выглядеть): бары в тоне стадий с линией «Сегодня»; KPI + бары по
  стадиям/исполнителям из реальных задач; workflow-схема с переходами и блоком
  «Автоматика схемы». Полноценный Гант — #39, редактор схем — #38. Витрине
  Ганта нужны `startDate`/`plannedMinutes` в контракте задачи (находка issue #4).
- **О проекте** — паспорт полями-реестром `EntityFields` (defs —
  `lib/project-passport.tsx`, ключ `nodus-project-fields-v1`; руководитель —
  переход в карточку сотрудника стеком).
- **Таб-бар — ТОЛЬКО вкладки + кнопка панели беседы** (вердикт раунда 4):
  чипов стадии/приватности НЕТ (приватность — полем в «О проекте»; **стадия
  проекта удалена как сущность** — из паспорта, колонок журнала и контракта
  `ProjectListItem`; справочник переоценим на бэкенде). Название — в хроме
  слайдера, в теле не дублируется.
- **Правая колонка — канал проекта** (создаётся АВТОМАТИЧЕСКИ, `channelId`):
  лента новостей-тредов + окно треда из `shared/chat` (`channel-view.tsx`,
  #42: широкая колонка — две зоны, узкая — drill-down с «К лентой»), видна
  ВСЕГДА — отдельной вкладки «Чат» нет; **шапки у чата НЕТ** (вердикт
  владельца: «чёрной области» нет в карточке задачи — и здесь нет); тоггл
  панели беседы — в таб-баре КАРТОЧКИ крайний справа (канон кнопки «О задаче»
  в полосе цепочки). Панель беседы (файлы/ссылки, области «Вся беседа / Этот
  тред» при открытом треде) — ВНУТРИ колонки чата справа: анимируется ОДНА
  ширина колонки — левая зона не дёргается; лента не уже 360px при открытой
  панели (колонка ≥ 660, тогда выталкивает левую зону — по правилу владельца).
  Перегородка колонки тянется с памятью (`shared/ui/use-chat-width.ts`, общая
  на все карточки); состояние открытого треда — у карточки (область панели
  беседы читает его оттуда же). Тёмная зона — структурный фон с первого кадра
  (`fadeContent=false`).
- **ОДИН канбан, а не два** (плейбук §3.1): задачи проекта — те же сущности
  (`GET /tasks?projectId=&stageId=`), колонки — стадии глобальной схемы
  (ADR-0008, до редактора #38 — дефолтная), DnD — `PATCH /tasks/:id`
  (оптимистично, откат снапшотом + тост); CRUD колонок НЕТ; quick-add —
  `POST /tasks {title, stageId, projectId}`. Механика борда — `shared/ui/board`
  - `shared/lib/board`.
- Список задач проекта — `DataTable` (ключ `projects.tasks`, shared-реестр
  `makeTaskTableFields({ projectVisible: false })`, плоский: граф-дерево — в
  навигаторе ветки карточки задачи); открытие карточки задачи — НАСЛОЕНИЕМ
  поверх карточки проекта (стек, ADR-0009).
- **Журнал проектов (страница):** каноническая таблица (`projects.list`) +
  шапка ОДНОЙ строкой (заголовок + счётчик + строка инструментов: поиск +
  фильтр-панель с пресетами «Я — руководитель»/«Открытые»/«Закрытые» и
  полями приватность/моя роль/руководитель/окончание — реестр
  `shared/views/project-filter-fields` + шестерёнка).

- Контракты: `ProjectListItem` (`channelId`; `stageName` удалён — вердикт
  раунда 4), `ProjectRef`; query `/tasks` (+`projectId`),
  `createTaskBodySchema` (+`stageId`/`projectId`).
- Эндпоинты (моки): `GET /projects`, `GET /projects/:id`; задачи проекта —
  общий ресурс `GET /tasks?projectId=`; своего `/projects/:id/tasks` нет.
- Хуки: `useProjectsList`, `useProjectDetail` (keepPreviousData — карточка
  не мигает в стеке), `useProjectTaskPages`, `useMoveProjectTask`,
  `useCreateProjectTask`.
