# features/chat

Мессенджер в теме «Инструмент»: **единый список бесед по активности БЕЗ
секций-заголовков** (вердикт владельца 2026-09-10, раунд 2 — чаты
перемешиваются по свежести; тип строки читается маркером на аватаре: канал —
мегафон, группа — участники, задача — список) + активная беседа справа
(механика Телеграма). **Поиск по беседам** — строка над списком (модель
Битрикс24 «Найти сотрудника или чат»: подстрока по названию и подписи/
последнему сообщению). Подразделы **«Чаты» / «Чаты задач» — в топбаре** по
канону каркаса (search `?tab=tasks`); чаты задач (`type=task`, привязка
`conversation.task`) — обсуждения задач с кнопкой «Открыть задачу» (карточкой
поверх, стек ADR-0009).

**Чат — карточка стека** (`chat:<conversationId>`, ADR-0009 п.7, вердикт
владельца 14.09.2026: «уточнить в чате, не закрывая карточку задачи»):
`components/chat-workspace.tsx` — ОБЩАЯ рабочая область беседы для страницы и
карточки (compact-шапка в карточке: имя/закладка в хроме слайдера; треды
карточки — локальное состояние). Служебная полоса открывает чат карточкой
поверх стека; верхняя чат-карточка подменяется новым собеседником.
Мессенджер-страница — полный режим со списком бесед.

**Тоны мессенджера (вердикт 14.09.2026: «зоопарк оттенков»):** список бесед и
весь хром (шапки, композеры, панели) — тон панели `card`; лента каналов,
личных чатов и тредов — ОДИН токен углубления `chat-zone` в обеих темах;
пузыри и вложения — `node-panel` поверх углубления; разделение зон —
hairline-линии, не ступени цвета.

**Ленты сообщений — серии по канону Битрикс24/Телеграм** (вердикты 14.09.2026,
план `docs/mvp/chat-messages-plan.md`): `shared/chat/message-groups.ts`
группирует подряд идущие сообщения одного автора в серии (разрыв — только
смена автора или календарного дня; чистые функции + unit-тесты). В серии: имя —
чужое и только у первого сообщения (в личных чатах имён нет вовсе), аватар
один — у ПОСЛЕДНЕГО (self-end; колонка аватара зарезервирована у всех
сообщений серии, пузыри на одной вертикали), ритм 2px внутри серии / 12px
между, при смене дня — дата-чип «Сегодня/Вчера/дата» (`day-chip.tsx`). Пузыри
чата БЕЗ рамки — вариант `card` Bubble-примитива (контур ступенью тона, рефы
Битрикс24); хвостик у последнего пузыря серии — ОДНА заливка SVG
(`bubble-tail.tsx`): силуэт сам несёт вогнутую кромку и закруглённый носик к
низу аватарки (линий нет — стык CSS-бордюра и SVG-обводки давал артефакты).
Время — ВНУТРЬ пузыря справа внизу + галочки отправлено/прочитано у своих
(`readAt` контракта; левая галочка поверх, правая прячется за ней; мок
«прочитывает» через ~2 с, отложенная инвалидация без polling). Реакции и
вложения — ВНУТРЬ пузыря: расширяют его по высоте (иначе аватар и хвостик
отлипают к строке реакций); при их наличии нижняя строка пузыря = реакции
слева + время справа в ОДНОЙ строке. Композер забирает фокус при входе в чат
(autoFocus; ремоунт по conversationId). Каналы-посты (`thread-feed`) — без
серий, хвостов и этой анатомии: грамматика новостей.

**Вложения (план `docs/mvp/chat-attachments-plan.md`, вердикт 14.09.2026):** схема
`messageAttachment` расширена ЗАРАНЕЕ под будущую загрузку и лайтбокс: `kind`
(image/file — явно, не из mime), `url`, `thumbnailUrl`, `width/height` (резерв
бокса до загрузки — лента без сдвига). Грамматика Битрикс24 внутри пузыря и
карточки поста СВЕРХУ ВНИЗ: галерея изображений → чипы файлов → текст →
нижняя строка (реакции + время). Галерея (`attachment-gallery.tsx`): одно фото —
крупное превью, 2–3 — ряд равновысотных плиток, 4+ — ряды по 3; `onOpen(index)` —
точка подключения будущего лайтбокса (портал, Esc/стрелки, счётчик). Чип файла
(`attachment-file.tsx`) — примитив `Attachment`: иконка по mime, имя (truncate),
размер, скачивание справа. Карточка поста канала (`thread-feed.tsx`): автор
сверху, вложения выше текста, реакции+время строкой, ответы — тонированной
полосой с аватарами и счётчиком («N ответов») и входом «Обсудить».

**Тёмная тема — без теней; композер — «вечный курсор» (вердикты 14.09.2026):**
тени рамы и слайдера (`frame-shadow`/`slider-shadow`) — ТОЛЬКО светлая тема;
в тёмной `none`: чёрная тень на почти чёрном читается разлитым пятном
(«неровные границы, будто разлитая жидкость»), элевацию держат ступени тона и
hairline-бордюры (Exa-research: Material M3, Atlassian — в тёмной теме
элевация тоном поверхности, тень там артефакт). Композер: скрепка вложений
слева, смайл и микрофон справа — ЗАГЛУШКИ до issues загрузки/эмодзи/голосовых
(схема вложений уже готова их принять); контур поля при активном курсоре НЕ
подсвечивается (фокус виден самим курсором). «Вечный курсор»
(`shared/chat/composer-focus.ts`, канон Телеграм): пока открыт чат/канал/тред —
каретка живёт в его композере; обычные клики по UI (карточки, кнопки, пустое
место) возвращают её; фокус передаётся ВНУТРЕННЕ только вручную другому
композеру (закрыли тред — курсор снова в ленте канала); клавиатурная навигация
и выделение текста фокус не отбирают. Порт связи пост→тред — вертикальная
середина правого края поста (`threadLinkSource`), не ось подвала.

**Контекстное меню беседы и лайтбокс (вердикт 14.09.2026 «всё отлично»):** ПКМ по
строке списка бесед — меню модели Битрикс24 (`conversation-menu.tsx`):
«Посмотреть позже» / «Закрепить»⇄«Открепить» / «Выключить звук»⇄«Включить
звук» / «Скрыть»; состояния читаются на строке глифами (булавка, перечёркнутый
колокол, часы), закреплённые — ВСЕГДА сверху списка (`sortByActivity`),
«посмотреть позже» прячет счётчик непрочитанных до нового сообщения, «скрыть»
убирает из списка (история сохраняется). Контракт: `pinned/muted/snoozed` в
`conversationListItem` + `conversationUpdateBody` (PATCH). Лайтбокс галереи
(`image-lightbox.tsx`): портал поверх интерфейса, Esc/задник — закрыть,
стрелки — листание, счётчик «N / M», фокус возвращается плитке; клик по плитке
галереи больше не заглушка. Вспышка контура шелла ЗАПРЕЩЕНА на сворачивание/
разворачивание панелей (флаг width-transition в `circuit-frame.tsx`: на
переходной геометрии пульс улетал поверх рейки — вердикт владельца).

**Каналы — лента новостей-тредов** (вердикт владельца 2026-09-10): каждое
сообщение канала — корневой пост (новость), ответы ссылаются на корень
(`threadRootId`, ровно один уровень). Тред открывается **ОКНОМ рядом с
лентой** (`shared/chat/channel-view.tsx`, #42; Slack-паттерн по research
slack.design: тред — отдельная панель, не оверлей и не замена ленты): две
зоны, у окна треда свой композер; перегородка тянется мышью с памятью
(`nodus-thread-w-v1`, `shared/ui/use-pane-width.ts` — императивный drag по
канону use-chat-width); открытие/закрытие — вталкивание шириной
(transition-[width], приём панели «О задаче»). Узкая зона канала (< 640px:
лента 320 + тред 320) — фолбэк drill-down: тред заменяет ленту с кнопкой
«К ленте» (прежнее поведение; в карточке проекта колонка обычно узкая —
там drill-down, пока не растянуть). Посты ленты сжимаются с лентой
(w-full max-w-2xl), перегородка ходит влево до минимума ленты 320
(вердикт владельца). При открытии/смене треда (и по
deep-link) — **вспышка контура** пост→порт окна, а после неё остаётся
**статичная связь** пост→тред с портами-точками (thread-link.tsx: связь —
структура, вспышка — событие; ребро следует за постом при скролле ленты,
источник следует за постом: пост видим целиком — точка-порт на нём; пост
не целиком в ленте — линия обрывается на кромке без точки и «ныряет под»
верх/низ чата (связь не прячется: видно, из какого поста тред и с какой
стороны пост искать; грамматика — circuit.md, длительности вспышки с caps
под широкоформатный монитор). Тред — search-параметр
`?thread=<rootId>` (deep-link). Посты ленты — ограниченной ширины
(`max-w-2xl`, референс — каналы Битрикс24: действия поста под ним, не на
другом краю экрана); счётчик ответов скрыт при нуле. Уведомления канала —
ТОЛЬКО участники треда и наблюдатели проекта (анти-спам; бэкенд-механика —
M13, в концепте не реализуется). Канал проекта создаётся автоматически при
создании проекта (`project.channelId`, см. features/projects — колонка
обсуждения карточки проекта рендерит тот же механизм из `shared/chat`).

Групповые/личные/задачи — обычная лента сообщений (MessageScroller +
Bubble-примитивы как в обсуждении задачи).

**Законы раунда 3 (вердикт владельца 2026-09-11):**

- **Правая панель беседы — в каждом чате** (`shared/chat/chat-side-panel.tsx`:
  файлы/медиа и ссылки из сообщений беседы). Канон — панель «О задаче»:
  тоггл — кнопка **СПРАВА ВВЕРХУ в шапке КАРТОЧКИ/страницы** (`ChatPanelToggle`;
  таб-бар проекта, полоса сотрудника, шапка беседы мессенджера h-14);
  **шапки у самого чата НЕТ** (вердикт: никаких «чёрных областей» с именем
  собеседника/названием канала). Панель — ВНУТРИ колонки чата справа:
  анимируется ОДНА ширина колонки (левая зона не дёргается); лента не уже
  360px при открытой панели (`MIN_FEED_WITH_PANEL` — минимум для панели
  беседы; при открытом окне треда минимум ленты 320 — `MIN_FEED_W`, #42,
  при панели и окне одновременно пол ленты 320; колонка ≥
  `MIN_COLUMN_WITH_PANEL` — тогда выталкивает левую зону, по правилу
  владельца). В карточке задачи её роль
  — панель «О задаче» (те же секции + история/избранное). Панель — ОДНА на
  беседу (хостится контейнером страницы/карточки): окно треда рядом с лентой
  НЕ дублирует её (research OpenClaw: несколько правых rail'ов съедают ширину
  ленты и множат границы ресайза); при открытом треде в панели — области
  «Вся беседа / Этот тред» (файлы/ссылки фильтруются по корню и ответам).
- **Контекстное меню сообщения** (`shared/chat/message-menu.tsx`): ТОЛЬКО
  правый клик по сообщению (никаких кнопок «⋯» — вердикт); якорь —
  виртуальный триггер по координатам, клампнутым в viewport (свои сообщения
  у правого края — без клампа меню уезжало за экран); реестр действий —
  ЗАГОТОВКА под бэкенд (работают «Копировать» и «Создать задачу» — поток Б;
  остальные — stub с тостом `actionSoon`; «Редактировать»/«Удалить» — только
  свои). Кнопки «В задачу» отдельно больше нет — она пункт меню.
- **Пустые состояния — канонический `Empty`** (как в журналах): лента беседы
  (`directEmpty`), лента канала (`feedEmpty`), список бесед, Гант. Пунктирных
  рамок-обрубков нет (исключение — drop-зона пустой колонки канбана: это
  affordance переноса, другая грамматика).

- **Механика чата — в `shared/chat/`** (потребители: мессенджер, карточка
  проекта, карточка сотрудника; I6 — фичи друг друга не импортируют):
  `api.ts` (ключи, сообщения беседы/треда, оптимистичная отправка с
  `threadRootId` и счётчиком корня, «В задачу», `useDirectConversation` —
  find-or-create личного диалога), `conversation-pane.tsx`, `thread-feed.tsx`,
  `thread-pane.tsx` (варианты шапки drill/side), `channel-view.tsx` (две зоны
  канала: лента + окно треда, перегородка с памятью, фолбэк drill-down),
  `channel-layout.ts` (пороги, геометрия связи, фильтр области — чистые
  функции с unit-тестами), `use-thread-link.ts` (хук механики связи и
  вспышки: замер по живым rect, слушатели скролл/resize/transition/drag,
  арминг вспышки), `thread-link.tsx` (статичная связь пост→тред +
  вспышка-событие),
  `chat-message.tsx`, `chat-composer.tsx` (бар h-16 —
  канон нижних баров, SendHexButton + кнопка панели беседы),
  `chat-side-panel.tsx` (области «Вся беседа / Этот тред»), `message-menu.tsx`;
  перегородки: колонка чата карточек — `shared/ui/use-chat-width.ts`, окно
  треда — `shared/ui/use-pane-width.ts`.
- Контракты: `ConversationListItem` (`type` + `'task'`, `task: TaskRef`),
  `ChatMessage` (`threadRootId`, `threadRepliesCount`),
  `sendMessageBodySchema`, `listMessagesQuerySchema` (+`threadRootId`).
- Эндпоинты (моки): `GET /chat/conversations`,
  `GET /chat/conversations/direct/:userId` (find-or-create диалога — чат
  карточки сотрудника; диалог с собой — «заметки для себя»),
  `GET|POST /chat/conversations/:id/messages` (+`?threadRootId=` — корень
  первым, POST в тред инкрементирует счётчик корня),
  `POST /chat/conversations/:id/messages/:messageId/to-task`.
- В фиче остаются: список бесед (`components/conversation-list.tsx`),

  `useConversations`.
