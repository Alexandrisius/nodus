# Фича notifications — web (#100, ADR-0016)

Живые обновления и уведомления на клиенте: экран «Главная» = витрина
компании (метрики, труд, дни рождения) с лентой журнала в центре (на месте
прежней новостной), колокольчик-поповер, индикация «число + точка», тосты
двух видов, карточка просмотра поверх ленты для срочных и записей без
источника. Данные — журнал на бэке (истина); WS только будит.

## Состав

- `api/notifications-api.ts` — query-хуки (лента/сводка/settings/acks),
  оптимистичные мутации read-one и ack (детерминированный тест: строка уходит
  из живых фильтров и сводки до ответа, история 'all' держит запись для
  карточки, откат при ошибке). Массового «прочитать всё» НЕТ — осознанное
  гашение только (фидбек владельца 01.10). Ключи — shared
  `notifications-keys.ts` (второй потребитель — сокет).
- `api/mocks/` — MSW-хендлеры домена `notifications` + демо-журнал
  (срочное с длинным текстом под гейт «долистал», действия-заделки, фон
  с горкой 999+). Демо-набор ПЕРЕПРИВЯЗЫВАЕТСЯ к реальным беседам аккаунта
  (догрузка /chat/conversations из хендлера): клик по мок-уведомлению на
  :5173 открывает настоящий чат. Фильтр 'all' — история целиком (включая
  прочитанные).
- `pages/home-feed-page.tsx` — маршрут Главной: витрина слотами `top`
  (метрики) и `rail` (труд/переработки/дни рождения) из app-слоя, центр —
  лента; при недоступности домена в колонке заглушка (витрина жива, I10/G4).
- `components/notifications-feed.tsx` — табы-счётчики (Все/Срочные/
  Упоминания/Действия, Slack-паттерн — один всегда активен) + поиск; группы
  по источнику (срочно→личное→действия), свёрнутый «ФОН», пустое
  состояние, onboarding.
- `components/notification-row.tsx` — строка: аватар · выжимка · источник
  (только название беседы/обсуждения — у личных источник = автор, дубля
  имени нет) · время · метка яруса. Клик — сразу карточка источника
  (Битрикс24-паттерн, `model/open-notification.ts`); срочное и
  безисточниковое — ридер.
- `components/notification-reader.tsx` — карточка просмотра: открывается
  ПОВЕРХ колонки ленты на Главной (не полноэкранная панель — метрики и
  дни рождения остаются видимыми; фидбек владельца 01.10), живёт в колонке
  ленты (home-feed-page). Срочное — лист ознакомления с гейтом «долистал»
  - «Перейти к источнику»; прочее — «Прочитать» + «Перейти к источнику».
    Открытое уведомление — `model/detail-store.ts`; открытие из другого
    раздела ведёт на Главную (`openNotificationReader`).
- `components/bell-popover.tsx` — колокольчик топбара: последние 5–7,
  клик — тот же сценарий, что в ленте (поповер закрывается); число
  важного / точка фона.
- `components/notification-toasts.tsx` — тост-контур: стак личного (≤4,
  «+1» при повторе автора ≤60 с, автоскрытие ~8 с, hover-пауза), сводная
  карточка действий (персистентная), aria-live=polite, z-[70].
- `model/toast-store.ts` — подавления: фон никогда; DND кроме срочного;
  muted/snoozed; открытый активный чат (B3–B8, F2/F4/F6).
- `model/use-pause-escalation.ts` — эскалация по паузам (Ф4): idle ≥30 с /
  смена раздела → одна мягкая волна «Требуют внимания: N», не чаще 1/5 мин.
- `model/group-notifications.ts` — группировка по источнику (Telegram-канон),
  сортировка ярусов, cap «999+» — чистые функции (unit).
- `model/use-notification-sink.ts` — приём WS-будил через shared-мост
  `shared/socket/notification-bridge.ts` (паттерн card-bridge).

## Интеграционные точки (вне фичи)

- `shared/notifications-keys.ts`, `shared/notifications-acks.ts` (мета чата
  «Срочно · Ознакомились N/M», live по WS), `shared/socket/*` (приём
  notification.*, точечная догрузка после reconnect), `app/shell/*`
  (колокольчик, бейдж рейки, document.title, ридер в AppShell).

## Мок-режим

Домен `notifications` в `VITE_API_MOCK` (csv) или `true`. На :5173 владельца
чат живой, уведомления можно держать на моках — фронт одинаков.
