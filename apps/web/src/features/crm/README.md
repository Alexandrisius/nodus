# features/crm

Раздел CRM (вердикт владельца 23.09.2026, issue #83; ADR-0033): дом
master-данных внешних организаций — рейка без зоопарка сверхмелких пунктов.
Сегодня одна вкладка «Контрагенты»: внешние организации — заказчики,
подрядчики, поставщики, госорганы + контактные лица. Договоры и тендеры —
будущие вкладки раздела: нарастают по вхождению тендерно-договорного контура
в план (V2, roadmap), вокруг уже существующего реестра. Лиды/сделки/воронки
НЕ моделируются и не планируются до входа контура. Корреспондент письма —
ссылка на контрагента (counterpartyRef), не строка (I15); у проекта — поле
«Заказчик» (контрагент).

Имя раздела в интерфейсе — «CRM»: осознанное исключение из канона
«только русская деловая» (ux-principles.md, вердикт владельца 23.09).

С #460 экран живёт на **живом API** модуля `crm` (`apps/api/src/modules/crm/`);
моки домена `counterparties` удалены — в `VITE_API_MOCK` этого домена больше нет.

## Состав

- `pages/counterparties-page.tsx` — вкладка «Контрагенты» раздела `/crm`
  (nav-registry): реестр канонической таблицей shared/views (ключ
  `counterparties.list`, колонки `lib/counterparty-fields.tsx`: название с
  пометкой «в архиве», полное название, УНП, счётчики писем/проектов/контактов;
  адрес, почта, телефон — скрыты по умолчанию). Бесконечная прокрутка по
  курсору, **серверный** поиск по названию/УНП (задержка 250 мс), переключатель
  «Показывать архивные»; счётчик — `N`, при недогруженных страницах `N+`
  (totals API не отдаёт). «Создать» — только с правом `crm.create`.
  Выделение строк ведёт ОБЩИЙ островок массовых действий
  (`shared/views/bulk-island.tsx`, каркас один на все модули; здесь —
  Меню строки («шашка») — полный набор команд (`lib/counterparty-row-menu.tsx`):
  «Открыть», «Копировать ссылку», «Изменить», «В архив»/«Из архива», «Удалить»
  (с подтверждением), по праву `crm.manage`.
  `components/counterparty-bulk-island.tsx`: «В архив» / «Из архива» /
  «Удалить», до 100 за раз, `POST /counterparties/bulk`, тост «изменено n из
  m»; состав действий зависит от выделения — «Из архива» не показывается,
  когда архивных среди выбранных нет).
- `components/counterparty-form-dialog.tsx` — окно создания и правки: полное и
  краткое название, УНП, почта, телефон, адрес; панель «Похожие в справочнике»
  (`similar-counterparties.tsx`) по мере ввода; точный УНП существующего
  контрагента блокирует «Создать» со ссылкой на него; окно не закрывается
  мимо-кликом (правило владельца 30.09.2026).
- `components/counterparty-card.tsx` — карточка в стеке (CardKind
  `counterparty`, ADR-0009). ЛЕВАЯ колонка — шапка и реквизиты (дефолт 50%
  ширины карточки, **перегородка тянется и помнит ширину** —
  `shared/ui/use-split-width.ts`, ключ `nodus-card-counterparty-split-v1`,
  закон выдвижных поверхностей), нижний бар h-16 с действиями слева («Изменить», «Перенести в
  архив», «Удалить» — по праву `crm.manage`; архивная карточка — read-only +
  «Вернуть из архива»). ПРАВАЯ зона — **вкладки связей** (эксперимент
  владельца 25.10.2026, обкатка перед вкладками карточки письма): бар h-10 как
  у карточек проекта/сотрудника, под ним — полноценные списки на shared-реестрах
  (строка инструментов + таблица + шестерёнка, «модули не отличаются»):
  - `counterparty-contacts-tab.tsx` + `lib/contact-fields.tsx` — «Контакты»
    (ключ `crm.contacts`): контакт — сущность со своими полями (модель
    Битрикс24), поэтому колонки, а не плитки. «Создать» (`crm.create`) слева
    от поиска; клик по строке — правка; меню строки — «Изменить», «В
    архив»/«Вернуть», «Удалить» (подтверждение). Окно — `contact-form.tsx`
    (монтируется только на время показа). Архивные — в конце с пометкой.
  - `counterparty-related.tsx` + `lib/related-letter-fields.tsx` — «Письма»
    (`crm.letters`: направление и рег.№, тема, дата, статус) и «Проекты»
    (`crm.projects`, единый реестр `projectListFields`). Обратные ссылки —
    только просмотр и переход в карточку: письмо рождается в корреспонденции,
    проект — в модуле «Проекты» (с #55 возможна кнопка «Написать» с
    подставленным корреспондентом). Запрос — только когда домен отвечает
    (моки dev-контура) или счётчик не пуст: до #55/#52 в живом контуре
    запроса к несуществующему API нет. Хуки — `shared/api/letters-list.ts`
    (`?counterpartyId=`) и `shared/api/counterparty-relations.ts`
    (`?clientId=`).
  - `counterparty-requisites.tsx` — реквизиты реестром полей (`EntityFields`,
    настройка видимости), почта — `mailto:`, телефон — `tel:`.
- `api/counterparty-edit.ts` — оптимистичные правка/архив/возврат контрагента
  и правка/архив/возврат контактного лица (патч карточки и строк реестра,
  откат снапшотом, I4).

## Общие части (shared, I6)

`shared/counterparties/` — потребители: эта фича и корреспонденция
(регистрация письма, композер), проекты:

- `keys.ts` — фабрика ключей (`pages`, `options`, `similar`, `detail`);
- `queries.ts` — `useCounterpartiesPages` (бесконечная прокрутка),
  `useCounterpartyOptions` (подсказки combobox), `useSimilarCounterparties`,
  `useCounterpartyCard`; `similarUnpQuery` — нормализация УНП общей грамматикой
  контракта (мусор и незавершённый ввод на сервер не уходят);
- `mutations.ts` — оптимистичное создание (темп в первую страницу только тех
  кэшей, чьим параметрам запись удовлетворяет, замена на месте) и добавление
  контакта;
- `use-crm-permissions.ts` — `useCanCreateCounterparties` (`crm.create`),
  `useCanManageCounterparties` (`crm.manage`); истина — сервер (I8);
- `counterparty-combobox.tsx` — автокомплит: серверный поиск, группа
  «Похожие», «Создать «…»» по праву, архивные помечены и не выбираются, без
  права — подсказка «добавлять может канцелярия или администратор».

Задержка ввода — `shared/lib/use-debounced-value.ts`.

## Контракты

`packages/contracts/src/counterparties/counterparty.schemas.ts`: `counterpartyRef`
{id, name}, `contactPerson` (+archivedAt), `listItem` (реквизиты, архив,
денормализованные счётчики — I14), `card` (+customFields, счётчики, метки
времени), `list` (search, includeArchived), `similar` + `match`, `create`,
`update`, `add/update contact`, `unpInputSchema` + `normalizeUnp`.
События — `events/crm-events.ts`, коды — `CRM_UNP_TAKEN`,
`CRM_COUNTERPARTY_ARCHIVED`, строки — `i18n/ru-crm.ts` (`ui.counterparties`).

## Моки

Моков контрагентов нет: домен живёт на бэкенде. `shared/mocks/data/counterparties.ts`
держит только ссылки (`counterpartyIds`, `counterpartyRefById`), общий ящик и
виды документов — их используют моки писем и проектов (до #55/#52). Мок
регистрации письма резолвит живого контрагента через `bypass()` — иначе
регистрация на :5173 падала бы 422 на живых контрагентах. Резолв живого
контрагента — общий `shared/mocks/live-counterparty.ts`: мок-фильтры
`/letters?counterpartyId=` и `/projects?clientId=` сопоставляют живую карточку
с демо-ссылками по id ИЛИ названию (демо-справочник песочницы заведён с теми
же названиями) — так вкладки «Письма»/«Проекты» на :5173 показывают демо-связи.

## Границы

Удаление — только записи без связей (дополнение ADR-0033), иначе архив. Письма и проекты фича только
ЧИТАЕТ через shared-хуки (cross-feature импорт запрещён). Запись кастомных
полей — #431 (здесь только чтение `customFields`); счётчики писем/проектов
наполнят обработчики #55/#52.
