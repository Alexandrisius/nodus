# features/home

Главная — «рабочий кабинет»: лента с оптимистичной публикацией слева, виджеты справа
(мои задачи с просроченными, письма с незарегистрированными, дни рождения).

- Контракты: `HomeSummary`, `FeedPost` (`@nodus/contracts`).
- Эндпоинты (моки): `GET /home/summary` (агрегат), `POST /home/feed`.
- Виджеты кликабельны: ведут в слайдеры задач/писем (навигация, не импорт фич).
