# features/home

Витрина компании для «Главной» в теме «Инструмент»: показатели (сотрудники,
завершённые проекты, накопленные узлы данных), график трудозатрат, топ по
переработкам, дни рождения. Сборка страницы — в app-слое
(`app/home-route.tsx`): блоки витрины — слоты `top`/`rail` вокруг ленты
уведомлений (центральная колонка, #100; новостная лента и её ридер-слайдер
удалены — фидбек владельца 01.10). Приветствие по времени суток + дата
(`HomeGreeting`) живут в полосе топбара шелла (вердикт владельца 12.09.2026).

- Контракты: `HomeSummary`, `CompanyStats`, `LaborWeek`, `OvertimeEntry`
  (`@nodus/contracts`); новостная часть контракта удалена вместе с рендером
  новостей (фидбек владельца 01.10).
- Визуал — только тема «Инструмент»: `node-panel`, `NodeCard`, `NodeChip`,
  `NodeLabel`, моно-метки; легаси-утилиты (paper-_, crayon-_) запрещены (DoD #4).
- Эндпоинт: `GET /home/summary` — живой (модуль `home` бэка: активные
  сотрудники, дни рождения справочника; метрики без источников — честные
  нули). Моки дева (`api/mocks/`) отдают тот же контракт с демо-данными для
  приёмки вида. Каркас витрины рендерится ВСЕГДА (вердикт владельца 01.10:
  видеть дизайн каждый день): блоки без данных показывают заглушку
  (`HomeEmptyHint`), сетка колонок и ширина ленты постоянны.
