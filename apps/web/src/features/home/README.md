# features/home

Главная — лента компании на «грифельной доске»: показатели (сотрудники,
завершённые проекты, выручка, накопленные узлы данных), посты-«бумага» новостей
с автором и счётчиками, дни рождения в правой колонке.

- Контракты: `HomeSummary`, `CompanyStats`, `CompanyNewsItem`
  (`@nodus/contracts`).
- Эндпоинты (моки): `GET /home/summary` (агрегат).
- Фон приложения — живой граф данных компании (`app/shell/live-graph`).
