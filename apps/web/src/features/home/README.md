# features/home

Главная — корпоративная витрина компании: показатели (сотрудники, завершённые
проекты, выручка, накопленные узлы данных), новости компании, «жизнь компании»
(фото) и дни рождения. Социальной ленты на главной нет — сообщения живут в
каналах мессенджера.

- Контракты: `HomeSummary`, `CompanyStats`, `CompanyNewsItem`, `CompanyPhoto`
  (`@nodus/contracts`).
- Эндпоинты (моки): `GET /home/summary` (агрегат).
- Фон приложения — живой граф данных компании (`app/shell/live-graph`).
