# features/home

Главная — лента компании в теме «Инструмент»: показатели (сотрудники,
завершённые проекты, накопленные узлы данных), плоские посты-панели новостей
с ридером-слайдером (стыковка док-ребром от карточки), график трудозатрат,
топ по переработкам, дни рождения в правой колонке.

- Контракты: `HomeSummary`, `CompanyStats`, `CompanyNewsItem`, `LaborWeek`,
  `OvertimeEntry` (`@nodus/contracts`).
- Визуал — только тема «Инструмент»: `node-panel`, `NodeCard`, `NodeChip`,
  `NodeLabel`, моно-метки; легаси-утилиты (paper-_, crayon-_) запрещены (DoD #4).
- Карандашные иллюстрации (`public/sketches/`) в теме «Инструмент» не
  используются; остаются для легаси-тем.
- Эндпоинты (моки): `GET /home/summary` (агрегат).
- Фон приложения — плоский; легаси-граф (`app/shell/live-graph`) монтируется
  только в нагрузочном режиме `?stress=N`.
