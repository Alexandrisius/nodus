# features/home

Главная — лента компании на «грифельной доске»: показатели (сотрудники,
завершённые проекты, выручка, накопленные узлы данных), крупные кликабельные
посты-«бумага» новостей с карандашными скетчами и ридером (Dialog), график
трудозатрат, топ по переработкам, дни рождения в правой колонке.

- Контракты: `HomeSummary`, `CompanyStats`, `CompanyNewsItem`, `LaborWeek`,
  `OvertimeEntry` (`@nodus/contracts`).
- Карандашные иллюстрации постов — `public/sketches/` (генерируются image-
  инструментом в стиле референсов; карта пост→скетч — в `home-news.tsx`).
- Эндпоинты (моки): `GET /home/summary` (агрегат).
- Фон приложения — живой граф данных компании (`app/shell/live-graph`).
