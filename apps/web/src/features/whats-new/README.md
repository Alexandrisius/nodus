# Фича whats-new — web (#386)

Окно «Что нового»: после обновления прода у каждого сотрудника один раз
выезжает правая панель с изменениями последнего выпуска, сгруппированными
по модулям рейки, с метками Новое / Улучшено / Исправлено; кнопка в топбаре
открывает историю всех выпусков. Бэкенда нет: тексты — данные в
репозитории, попадают в бандл сборкой. Выпуск и тексты пишет агент по
навыку `nodus-release` (триггер владельца «ОБНОВИТЬ ПРОД»).

## Состав

- `releases/<X.Y.Z>.json` — один файл на выпуск (параллельные выпуски не
  конфликтуют); имя = версия = тег `vX.Y.Z` на main. Поля и правила текстов
  — навык `nodus-release` (`references/writing-guide.md`).
- `model/release-schema.ts` — zod-схема выпуска (strict), типы изменений и
  их порядок, `compareVersionsDesc` (semver, `0.10 > 0.9`).
- `model/releases.ts` — загрузчик (`import.meta.glob` eager): невалидный файл
  пропускается с `console.warn`, портал не падает; `RELEASES` (новые
  первыми), `LATEST_RELEASE`.
- `model/releases.test.ts` — **страж данных в CI**: строгая схема, имя файла
  = версия, модули только из реестра, без дублей, без технического жаргона
  (номера issue, API, Redis, токен, миграция…).
- `model/group-release.ts` — модули = единый реестр навигации
  (`app/shell/nav-registry.ts`: иконка и название как в рейке) + «Общее»;
  группировка в порядке рейки, внутри — новое → улучшено → исправлено;
  неизвестный id → «Общее»; чипы фильтра — только модули с изменениями.
- `model/whats-new-store.ts` — persist `nodus-whats-new-v1` (zod-envelope
  в `shared/lib/persist-zod.ts`): последний просмотренный выпуск ПО
  ПОЛЬЗОВАТЕЛЮ (`userId → version`, общий компьютер — у каждого своя
  отметка); открытие = просмотр.
- `model/use-whats-new-auto-open.ts` — автопоказ в каркасе через 1,2 с после
  входа, если последний выпуск не просмотрен; фокус у рабочего места не
  крадётся (`openReason: 'auto'`). Под автоматизацией браузера
  (`navigator.webdriver` — Playwright e2e, ui-reviewer) автопоказа НЕТ:
  панель перехватывала фокус и клики критичных путей; в пробах её открывают
  кнопкой топбара.
- `components/whats-new-panel.tsx` — парящий лист справа на примитиве
  `Sheet` (геометрия карточек-слайдеров: inset 8px, радиус рамы,
  `--slider-shadow`, прозрачный click-catcher вместо затемнения —
  `overlayClassName`); шапка h-14 + крестик у края, чипы-фильтры модулей,
  последний выпуск раскрыт, предыдущие — свёрнуты под «Предыдущие
  обновления».
- `components/release-section.tsx` — выпуск: «Обновление от <дата>» + моно-
  версия, строка-итог, блоки модулей (иконка + `NodeLabel` со счётчиком),
  пункт — плитка `bg-muted/50` с `NodeChip` типа (success/info/muted).
- `components/whats-new-button.tsx` — кнопка `Sparkles` в топбаре (слева от
  колокольчика), точка `bg-info` — выпуск не просмотрен; выпусков нет —
  кнопки нет.

## Интеграционные точки (вне фичи)

`app/shell/app-shell.tsx` (панель + автопоказ), `app/shell/top-bar.tsx`
(кнопка), `shared/lib/persist-zod.ts` (envelope), строки —
`packages/contracts/src/i18n/ru-whats-new.ts` (`ui.whatsNew`).

## Ограничения

- Открытая вкладка получает новый бандл (и окно) только после перезагрузки
  страницы — уведомления «вышла новая версия» нет.
- «Просмотрено» живёт в браузере: на другом устройстве окно покажется ещё раз.
