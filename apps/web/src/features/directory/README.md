# features/directory

Сотрудники в теме «Инструмент»: два вида (вердикт владельца 2026-09-10) —
**Структура** (граф оргструктуры) и **Список** (каноническая таблица), вкладки
в топбаре (search-параметр `view`).

- **Граф оргструктуры** (`components/org-chart.tsx`) — по грамматике контура
  Nodus: узлы — плоские node-панели (аватар + имя + должность), связи —
  ортогональные рёбра 1px на токене `--edge` с портами r=3 у верхнего края
  карточки подчинённого (порты только на целевом конце, как NodeEdge
  `ports='end'`). Каждый сегмент — ровно один штрих (gotchas SVG-графа):
  на группу «руководитель → дети» — шина (одна горизонталь), ствол (одна
  вертикаль) и отводы к портам (T-стыки без наложений сегментов — иначе
  градиент яркости из сложения полупрозрачных stroke); координаты прямых —
  `snapPx`. Обмер живого DOM (ResizeObserver), дерево по `managerId`.
- **Список** — `DataTable` (shared/views, ключ вида `employees.list`, реестр
  `lib/employee-fields.tsx`: сотрудник, должность, подразделение, почта,
  руководитель — резолвится из того же списка, HR-статус скрыт по умолчанию).
- **Карточка сотрудника** (`components/employee-card.tsx`, стек карточек
  ADR-0009) — анатомия карточки задачи (вердикт владельца 2026-09-11,
  раунд 3): **левая зона** — вкладки на всю высоту: **Профиль** (полный
  `UserCard` полями-реестром `EntityFields`, ключ `nodus-employee-fields-v1`:
  должность, подразделение, почта, телефон, город, кабинет, удалёнка, ставка,
  пол, день рождения, дата приёма, начало дня, руководитель — переход стеком,
  HR-статус + секция «Подчинённые»), **Задачи** (`GET /tasks?assigneeId=`) и
  **Проекты** (`GET /projects?memberId=`) со счётчиками — ПОЛНОЦЕННЫЕ журналы
  на shared-реестрах (`makeTaskTableFields()` / `projectListFields`, ключи
  видов `directory.tasks` / `directory.projects`): все поля + шестерёнка
  отображаемых полей в таб-баре (как в карточке проекта) + ресайз колонок,
  как в модулях («модули не отличаются», вердикт); связи открываются
  карточками поверх (стек). **Правая колонка — личный диалог с сотрудником
  ВСЕГДА** (find-or-create, `GET /chat/conversations/direct/:userId`, хук
  `useDirectConversation` в shared/chat; диалог с собой — «заметки для
  себя»); шапка колонки (собеседник + тоггл панели справа вверху);
  перегородка тянется с памятью (общая на все карточки); панель беседы
  (вталкивающая) и контекстное меню сообщений — из shared/chat. Кнопки
  «Написать сообщение» больше нет — чат уже здесь. Полоса — аватар-якорь +
  presence-чип + позиция (имя — в хроме слайдера).
- Связи сотрудника — `shared/api/user-relations.ts` (`useAssigneeTasks`,
  `useMemberProjects`): I6 запрещает фичам импортировать друг друга, поэтому
  хуки на публичные list-ресурсы — в shared-слое.
- Контракты: `UserListItem`, `UserCard` (полный профиль), `PresenceEntry`;
  query `/tasks` (+`assigneeId`), `/projects` (+`memberId`).
- Эндпоинты (моки): `GET /directory/users?limit=50`,
  `GET /directory/users/:id` (UserCard), `GET /directory/presence`.
- Открытие карточки — shared-element из rect узла графа/строки списка;
  закрытие сохраняет вид (`view`).
