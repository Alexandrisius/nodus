# Каталог — ТОЛЬКО для песочницы (:4173)

Проверочная фикстура кнопки «Скачать приложение» (#263): `vite preview`
раздаёт `public/` как корень, поэтому на песочнице манифест живёт здесь. В
проде этот каталог пуст — раздачей `/desktop/` занимается nginx web-контейнера
из `NODUS_DESKTOP_DIR` (alias перекрывает любые файлы из dist).

Содержимое НЕ коммитится (см. `.gitignore`). Для приёмки положить сюда:

- `latest.json` — сгенерировать `node scripts/desktop-manifest.mjs --out`
  и заменить url на абсолютные `http://127.0.0.1:4173/desktop/...` (в песочнице
  нет nginx `sub_filter`, который абсолютизирует относительные пути);
- установщик `Nodus_<версия>_x64-setup.exe` — из
  `apps/desktop/src-tauri/target/release/bundle/nsis/`.
