# desktop — серверная сторона десктоп-оболочки

Модуль M17 (#254, ADR-0019): тонкий Tauri-клиент портала. Логика оболочки
живёт в `apps/desktop`; здесь — только контракт с ней.

## Назначение

- `GET /api/v1/desktop/config` — публичный (без авторизации): `serverName`
  (идентификация сервера на экране подключения/смены сервера) и
  `minShellVersion` (минимальная поддерживаемая версия оболочки; оболочка
  старше минимума показывает экран «обновите приложение» вместо тихих ошибок
  контрактов). Оболочка спрашивает конфиг до входа пользователя.

## Контракты

- `desktopConfigSchema` — `packages/contracts/src/desktop/desktop-config.schema.ts`.

## Конфигурация (env)

| Переменная                | По умолчанию | Смысл                                |
| ------------------------- | ------------ | ------------------------------------ |
| `NODUS_SERVER_NAME`       | `Nodus`      | Отображаемое имя сервера портала     |
| `NODUS_MIN_SHELL_VERSION` | `0.0.0`      | Минимальная версия оболочки (semver) |

## События

Модуль не издаёт доменных событий: чтение статической конфигурации, сущностей
не касается. Обновления самих клиентов идут статикой `GET /desktop/`
(nginx, `NODUS_DESKTOP_DIR`) — см. runbook `docs/runbooks/desktop-deploy.md`.

## Лимиты

- Эндпоинт публичный и лёгкий (без БД): общий IP-rate-limit приложения
  достаточно; отдельного троттлинга не требует.
