# Модуль home — витрина Главной (#100)

Читающий агрегат `GET /api/v1/home/summary` для корпоративной витрины на
Главной (вокруг ленты уведомлений): метрики компании, дни рождения, заделы
трудозатрат. Модуль ядровой (не отключается флагом — Главная есть всегда,
I10).

## Состав

- `home.controller.ts` — единственный роут `GET /home/summary` (auth —
  глобальный JwtAuthGuard; OpenAPI-аннотации стандартные).
- `home.service.ts` — агрегация: активные сотрудники (счёт), дни рождения
  из справочника; метрики без источников (проекты, «узлы данных»,
  трудозатраты) — честные нули/пустые массивы до появления своих модулей.
- `birthdays.ts` — чистая функция выбора ближайших годовщин (окно 14 дней,
  флаг «сегодня», сортировка по близости, лимит 8; 29 февраля в невисокосный
  год съезжает на 1 марта) — покрыта юнит-тестом `home.service.test.ts`.

## Контракт

`HomeSummary` (`@nodus/contracts`, home-summary.schemas.ts): `{ stats,
birthdays, labor }`. Клиент пустые блоки (labor без данных, дни рождения
без строк) не рендерит — на проде без данных витрина показывает только
карточки метрик с честными нулями.
