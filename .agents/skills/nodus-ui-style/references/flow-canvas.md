# Холст схем (ADR-0022, #378)

Единый движок схем — `apps/web/src/shared/flow/` (редактор маршрутов,
«Схема маршрута» задачи, будущие схемы проектов). Референс — Jira workflow
editor: свободный канвас, никаких колонок-контейнеров.

## Раскладка (route-layout.ts, чистая)

- Слои слева направо по длиннейшему пути от начального статуса; циклы
  разрывает DFS (обратные рёбра не участвуют); кнопки «из любого» считаются
  исходящими от старта; недостижимые (ошибка схемы) — за достижимыми.
- Геометрия: узел 208×52, коридор между слоями 132 (там живут подписи),
  вертикальный ритм 64, поля 48. Внутри слоя порядок: этап → sortOrder → id.
- Ручное перетаскивание: позиции хранятся в черновике клиента
  (`positions` конверта localStorage), в документ публикации НЕ попадают и
  undo-историю не засоряют; сбрасываются discard/публикацией.
- «Схема маршрута» (чтение) — без позиций: раскладка детерминирована.

## Рёбра (edge-routing.ts, чистая)

- Линия НЕ пересекает карточки: соседний слой — правый порт → веридор →
  левый порт; возврат/дальний ход — нижняя магистраль под схемой (низ → низ,
  подпись у источника); вниз внутри слоя — вертикаль, вверх — правый обход.
- Параллельные кнопки одной пары — свои коридоры/магистрали с шагом.
- Путь — свой SVG с мягкими локтями (`roundedOrthPath`, r=10) + невидимая
  широкая линия для попадания клика; стрелка — MarkerType (цвет через CSS —
  var() в fill-атрибуте не работает).
- Подпись-чип по показу кнопки: primary — залитый, button — карточка с
  рамкой, menu — пунктир + приглушённый.

## Узлы и хром

- Узел статуса: полоса цвета статуса слева (токены stage-tone), название
  13px + подпись этапа 10px uppercase; маркеры: «Начальный», итог ✓/✕,
  проблема ⚠. Выбран — кольцо, текущий статус задачи — свечение.
- Пилюли «из любого» — у правого верхнего угла цели (реф Jira Any-lozenge).
- Старт — пунктирная пилюля «Создание задачи» слева от начального.
- Тулбар редактора h-14 с border-b; зум — в тулбаре, атрибуция React Flow —
  правый нижний угол (не пересекаются); фон — точечная сетка токеном
  (`.react-flow__background circle { fill: var(--edge) }`).
- Инспектор — внутриоконная панель (border по периметру, радиус 14,
  transition-width, всплывает ПОД строкой инструментов).

## Антипримеры

- Колонки-этапы контейнерами (бэнды) — владелец отверг 19.10: «такие колонки
  на канвасе никто не отображает»; этап читается подписью в узле.
- Подписи кнопок за узлами / на узлах — только коридоры и магистраль.
- `@xyflow/react/dist/style.css` — чужая тема; только `base.css` + `--xy-*`.
