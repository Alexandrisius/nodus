# Контур Nodus — связи, вспышки, хореография

Код: `apps/web/src/app/shell/circuit-geometry.ts` (измерение/пути), `circuit-frame.tsx` (рендер + пульс). Контур — фирменная навигационная связь: шина рейки → стык → ось шапки до правого края вьюпорта.

## Геометрия — измерение живого DOM (никаких констант позиций)

Контур достраивается сам при добавлении модулей/вкладок — измеряет элементы по data-атрибутам:

| Атрибут | Где | Что даёт |
|---|---|---|
| `data-topbar` | шапка | ось = bottom шапки; правый край = `clientWidth` |
| `data-module-port` (+`data-active`) | пункты рейки | порты модулей (PORT_X=42) |
| `data-tab-port` (+`data-active`) | вкладки топбара | точки вкладок |
| `data-left-node` | шов схлопнутого меню | единственная точка 5px при collapsed |

- **Артерия — одна ломаная** с круглыми сопряжениями (не подпути — иначе прямые углы на стыках): низ шины → стык (БЕЗ точки) → ось до правого края.
- **Равномерность hairline 1px:** прозрачность контура — CSS-opacity на ОТДЕЛЬНОМ svg + `will-change: opacity` (форс композитного слоя): без слоя Chromium сворачивает opacity в alpha кисти, и самопересечения подпутей (подходы отводов к шине, засечек к оси) удваивают яркость — «хвостики ярче шины» при зуме ≤ 100% (`<g opacity>` и svg-opacity без will-change НЕ помогают). Прямые координаты — через `snapPx()` (полупиксель устройства, devicePixelRatio учитывает зум): линия на целой координате размазывается на две полуполосы и выглядит тусклее дробной (механизмы и замер — `docs/gotchas.md`).
- **Шина** одним блоком: конец = точка отхода последнего отвода (порт − 10, без хвоста); отводы — локти к портам.
- **Засечки вкладок** — локти ВВЕРХ к точкам вкладок (TICK=12), по одной у пункта; на оси точек нет.
- **Стык и лого — без точек всегда.** Порты рисует NodeEdge (`ports='end'` — точка только в целевом порту).
- Панели двигаются — контур пересчитывается **покадрово (rAF-loop)**, фильтр `propertyName === 'width'` (см. ловушку ниже).

## Вспышка (nav-пульс)

- **Ровно одна**, всегда ОТ ПОРТА МОДУЛЯ по шине и оси К ТОЧКЕ АКТИВНОЙ ВКЛАДКИ — клик по модулю и по вкладке дают одну траекторию.
- **Только на смену фокуса**: фокус = `moduleTo | tabLabel` (не координаты!) — resize, сворачивание панелей вспышки не вызывают (sig по tabLabel, не по tabX).
- Скорость 400 px/s; длительность = длина/400; затухание подсветки тоже ∝ длине (fadeMs = draw + пульс + 0.9 с).
- **Главная — без вспышки вообще**; точки у логотипа нет. Модуль без вкладок — обрубок за стык без точки.
- В схлопнутом меню — пульс от точки бокового шва по оси к вкладке; портов внутри схлопнутого меню нет.

## Слайдер-нода (док-ребро)

Стыковка панели с источником: точка клика пробрасывается через `useShellStore.lastDock` → `SliderPanel dockFrom` (фиксируется на маунте и сбрасывается — прямые ссылки без ребра).

**Хореография (утверждена):** панель стартует с задержкой 150 мс (`animationFillMode: 'backwards'`) — глаз сначала видит, как ребро растёт от строки/карточки к раме; затем панель накрывает источник, ребро тает за 1 с (`dock-edge-fade`). Корень прошлого бага «линия висит в воздухе»: панель накрывала источник одновременно с ребром.

## Ловушки анимаций (детали — `docs/gotchas.md`, фронтенд)

1. **SMIL `<animateMotion>` без `fill="freeze"` и opacity-гейта** — элемент возвращается в (0,0): «светящийся пиксель» в левом верхнем углу. Обязательно: `fill="freeze"` + `<animate attributeName="opacity">` на begin.
2. **`transitionend` приходит на каждое свойство и всплывает** — цикл слежения фильтровать по `event.propertyName` (у нас `'width'`), иначе глохнет от посторонних анимаций.
3. **`animationend` всплывает** — фильтровать по `event.animationName` (дочерний draw-on завершит логику родителя раньше времени).
4. SMIL не стреляет DOM-событиями — «один пробег и убрать» таймаутом/перемонтированием через `key`.

## Панели каркаса (утверждённые правила)

- **Правая полоса:** под главной линией (`absolute top-14 right-1.5`), 40px ⇄ 240px по dwell **800 мс**, поверх контента; БЕЗ кнопки скрытия, заголовка, цифры онлайн и видимого скроллбара (`data-no-scrollbar`); аватары 28px.
- **Скроллбар контента** — у левого шва полосы: `#content { padding-right: 46px }`, 3px `var(--scrollbar)`.
- **Аватар профиля** — по центру свёрнутой полосы (`-mr-2.5`).
- **Кнопки сворачивания панелей** — только шевроны 16px, без текста и разделительных линий.
- **Меню:** плашка ховера `mx-3`, бейдж `pr-2.5`; схлопнутое — точка 5px на боковом шве, порты не рендерятся.
- **Топбар** без «Создать»; вкладки модулей — в `top-bar.tsx → sectionsFor()` (новая вкладка — сюда, контур достроит сам).
