# Токены «Инструмента» (обе темы)

Источник истины — `packages/ui/src/styles/globals.css`. Компоненты используют только семантические Tailwind-классы на токенах (`bg-background`, `text-muted-foreground`, `border-border`, `bg-edge`…); хардкод hex/rgb запрещён.

## Светлая (ДЕФОЛТ — вердикт владельца 15.09.2026, `:root` без атрибута)

Отдельный дизайн, НЕ инверсия тёмной (вердикт команды владельца 2026-09-11, реф `docs/mvp/ref/node-based UI/реф_белая тема_*.png`): три ЧИТАЕМЫЕ ступени поверхностей (серый шелл → бумажный холст → «лист» `#FBFAF9`; НЕЙТРАЛЬНО-тёплые — жёлтый подтон урезан вдвое, вердикт 12.09.2026; ЧИСТОГО БЕЛОГО нет вовсе — большие площади `#FFFFFF` дают блик и «однотонную белизну», audit 12.09.2026), hairline-бордюры, элевация ступенью; фирменный navy `#16233A` — хирургический акцент (primary, фокус, чекбоксы, активный модуль); контур/порты — «чертёжный синий» (navy с alpha).

## Categorical-палитра данных (`--chart-1..6`)

Цвет = смысл: графики и маркеры идентичности (плитки проектов), в хром UI не протекает. База — Okabe-Ito (colorblind-safe): светлая — оригиналы (`#0072B2`, `#009E73`, `#E69F00`, `#CC79A7`, `#56B4E9`, `#D55E00`); тёмная — осветлённые производные (`#64A4E0`, `#5FBF8F`, `#E0B054`, `#D795BC`, `#8CC8EA`, `#E08A66`). Потребители: `identityTone`/`chartRowTone` (`shared/ui/identity-tone.ts`), SVG-бары через `var(--chart-N)`.

## Типографика

- **Onest Variable** — весь интерфейс (`font-sans`). Лестница ФИКСИРОВАНА в px и НЕ зависит от масштаба интерфейса (плотность и типографика регулируются независимо, density Material/Fluent; #60 раунд 2): body 15px (`text-sm`), плотный контент и ячейки таблиц 14px (`text-body-xs`), метки полей и заголовки таблиц/секций 13px (`text-xs`/`text-label`), навигация (модули рейки и подмодули топбара) 15px, титул карточки-панели 18px (`text-lg`), приветствие Главной 18px, KPI 28px (`text-stat`). Калибровка — enterprise-канон (research Exa) + живые замеры Битрикс24 (21.09.2026: меню 15px/400, канбан 14px, титул 21px/600, меню 240px, ряд 38px).
- **JetBrains Mono Variable** — ТОЛЬКО данные (`font-mono`): номера, коды, время, длительности, счётчики, оси Ганта/схемы, ключ-чипы карточек и рейки; 11–12px, `tabular-nums`. НЕ метки: заголовки секций/таблиц — `NodeLabel` = sans 13px semibold UPPERCASE tracking 0.08em; статус-чипы — sans 12px (раунд 2 #60: вердикт тестировщиков «два шрифта, второй огромный»; паттерн Битрикс24 — одна гарнитура: метка мельче и серее, значение крупнее и чёрное).
- Заголовки экранов: `text-xl font-semibold`; сущности: `text-lg font-semibold`.
- Масштаб интерфейса: `--ui-scale` (дефолт 1.25) на корневом шрифте — масштабирует ТОЛЬКО rem-утилиты (spacing, высоты контролов, радиусы); JS-геометрия — `uiPx()` (`shared/ui/ui-scale.ts`); шаги дискретные 0.9/1.0/1.125/1.25. Кастомные text-* токены зарегистрированы в группе font-size tailwind-merge (`packages/ui/src/lib/utils.ts`) — иначе merge глушит кегль тоном (gotchas).

## Радиусы и ритм

- Лестница радиусов (пакет мягкости, вердикт владельца): контролы 8–10px (`--radius` 0.625rem), **поверхности (node-panel, поповеры, меню, селекты) — 14px (`--radius-xl`)**, рамы — 18px; локти рёбер 6–8px; порты r=3 (узел сворачивания ветки r=7).
- Сетка — 8px-ритм (`p-2/3/4/5/6`, `gap-2/3/4/5`).

## Механика тем

- `shell-store` (`ThemeId = 'dark' | 'light'`, `toggleTheme`), persist `nodus-shell-v1` (partialize — theme + edgeOpen). ДЕФОЛТ — `'light'` (вердикт владельца 15.09.2026).
- Светлая живёт в `:root` без атрибута — первый визит отрисовывается сразу светлой, без вспышки тёмной; `app-shell` для светлой УДАЛЯЕТ `dataset.theme`, для тёмной ставит `'dark'`; `<Toaster theme={theme}>`.
- Inline-скрипт `index.html` (до первой отрисовки) читает persisted `nodus-shell-v1` и ставит `data-theme='dark'` вернувшемуся «тёмному» пользователю — без вспышки светлой; `theme-color` meta = `#F4F2F0` (фон дефолтной темы).
- Скроллбар — через `var(--scrollbar)` (не хардкод!).

## Запреты стиля (grep-контроль DoD)

`paper-`, `crayon`, `sketch`, `texture-`, `bg-rust`, `text-ochre`, `text-cream`, `bg-sage`, `bg-steel`, `bg-tealink`, `border-pencil`, `bg-cream`, rose-цвета, хардкод-цвета в классах (`bg-[#...]` разрешён только внутри токенов globals.css), тени/градиенты/текстуры, translate-«приподнимание» карточек при ховере (ховер — только цвет: `hover:border-input`, `hover:bg-accent/40`; ховер ЦЕЛОЙ карточки на холсте — `/60`, иначе сливается с холстом), толстые фокус-ринги (фокус = `border-ring` + `ring-1 ring-ring/30`, вердикт владельца 11.09.2026).

## Фон-граф (утверждённая концепция, реализация — отдельной итерацией)

Не «космос», а наша грамматика: слабая статичная схема из ортогональных рёбер и портов (без движения и пульсов), alpha ≈ 5–8%: в тёмной — «созвездия», в светлой — «чертёж на кальке». Плотность узлов = накопленные данные.
